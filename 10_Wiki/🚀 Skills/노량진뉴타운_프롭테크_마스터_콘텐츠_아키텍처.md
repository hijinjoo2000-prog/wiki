# 노량진뉴타운 프롭테크 콘텐츠 마스터 아키텍처 v2.0

## 📌 한 줄 포착 (The Karpathy Summary)
> 본 시스템은 단순한 블로그 포스팅을 넘어, **'데이터 수집(Python/Selenium) $\rightarrow$ 전문 페르소나 주입(서프로) $\rightarrow$ 자체 검증(Anti-RAG)'**의 5단계 파이프라인을 거쳐 네이버 C-Rank 및 DIA+ 알고리즘에 최적화된 상위 1% VVIP 전용 지능형 콘텐츠를 자동 생성하는 시스템 설계 보고서이다.

## 📊 구조화된 지식 (Synthesized Content)
### Ⅰ. [목표] 시스템의 존재 이유와 목표 시장 설정
*   **핵심 목표:** 단순 트래픽 유발이 아닌, **'신뢰도(Trust)'와 '전문성(Expertise)' 기반의 독점적 정보 제공**을 통해 블로그 저품질 위험을 원천 차단한다.
*   **타겟 고객 (Persona):** 상위 1% 자산가 및 투자자 ("우리 프밀리님들!")
*   **지향하는 가치:** 법률적 근거 기반의 투명성, 예측 가능한 수익 분석, 현장감 있는 스토리텔링.

### Ⅱ. [기술 아키텍처] 콘텐츠 자동 생성 파이프라인 (5-Layer System)
| 레이어 | 기능 및 역할 | 주요 기술/규칙 | 목적 |
| :--- | :--- | :--- | :--- |
| **1. Data Fetching** | 검색 엔진(VIEW 탭) 크롤링 및 원시 데이터 수집. | Selenium, BeautifulSoup, KoNLPy (LSI 키워드 추출). | *최신 트렌드/경쟁사 분석* |
| **2. Data Bridge** | 여러 출처의 파편화된 데이터를 구조적 JSON 형태로 통합 전송. | `zone_shared_data.json` 활용 (수기 입력 배제). | *데이터 무결성 확보* |
| **3. Generation** | 정교한 페르소나(서프로)를 주입하여 1차 초안 작성. | VVIP 브리핑 5단계 구조 준수, 최소 1,500자 이상 분량 강제. | *콘텐츠의 질적 완성도* |
| **4. Self-RAG & Anti** | AI가 생성한 원고를 검열관(Anti)이 3대 토큰으로 교차 검증. | ISREL (목적), ISSUP (팩트 일치), ISUSE (유용성). Fail 시 강제 재작성 루프 돌입. | *환각 방지 및 신뢰도 극대화* |
| **5. Posting & Automation** | 완성된 원고를 사람이 타이핑하는 리듬을 모사하여 포스팅한다. | `pyperclip` (클립보드 사용), PyQt6 기반 GUI 자동 제어. | *봇 탐지 회피 및 효율성 확보* |

### Ⅲ. [콘텐츠 작성 규정] 핵심 가이드라인
1.  **페르소나 유지:** 전 과정에서 '서프로'의 현장감 넘치고 자신감 있는 구어체(-습니다, -해요)를 일관되게 유지한다.
2.  **SEO 구조 준수:** 모든 콘텐츠는 **후킹 $\rightarrow$ OCR 브리핑 $\rightarrow$ 미래 가치 $\rightarrow$ 수익 분석 $\rightarrow$ 법률 컨설팅**의 5단계 흐름을 따른다.
3.  **절대 금지 항목 (생명선):** 허위 수치 계산(숫자 환각), 근거 없는 대출 언급, 모호한 시간 부사("최근") 사용은 절대 불가하다.
