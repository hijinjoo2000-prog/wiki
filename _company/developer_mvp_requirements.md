# 💻 MVP 개발 요구사항 (지식 저널 + 유료 컨설팅)

## 1. 기술 스택 및 환경
- **프론트엔드**: React.js / Next.js
- **백엔드**: Node.js / Python (FastAPI)
- **데이터베이스**: PostgreSQL
- **결제 연동**: Stripe Connect API
- **호스팅**: Vercel / Heroku

---

## 2. 기능 요구사항

### M1: 결제 시스템 구현
- **Stripe Connect 연동**
    - 구독자 관리 및 번들 옵션 결제 처리
    - 환불/취소 로직 구현
- **결제 페이지**
    - 가격 전략에 따른 UI 렌더링
    - 결제 성공/실패 처리 알림

### M2: 콘텐츠 게시 및 문의 폼
- **게시글 CRUD API**
    - 카테고리별 필터링
    - 무료/유료 태그 설정
- **문의 폼 연동**
    - 유저데이터 수집 (이름, 연락처, 문의 내용)
    - 결제 정보 포함 (Stripe 연동)

### 구독 관리 페이지
- 현재 구독 상태 확인 및 변경
- 결제 주기 변경 (월간/연간 전환)
- 취소 옵션 제공
