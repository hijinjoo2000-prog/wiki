# MVP 기능 우선순위 및 수익 효율성 분석 (현빈)

## 1. 현재 APP 핵심 기능과 개발 난이도 평가

| 기능 | 개발 난이도 | 예상 유지비 | 유료 전환 가능성 |
|------|------------|--------------|------------------|
| 카드 생성기 | 낮음 (레거시 코드 기반) | 낮음 | 무료 (유입용) |
| 블로그 자동 작성 | 중간 (Gemini API + prompt 엔지니어링) | 중등도 (API 비용) | **높음** |
| 재개발 투자 분석 | 높음 (외부 API 연동 필요) | 높음 (클라우드, 데이터 구독) | 불명확 |

## 2. MVP 기능 우선순위 결정

### 목표: 개발 시간 최소화 + 초기 매출 극대화

1. **카드 생성기 (무료)**  
   - 이유: 시니어 중개사들의 가장 큰 니즈는 '시간 절약' → '3 번 클릭으로 매물 카드 제작'
   - 전략: 무료 체험을 통해 앱 사용성을 검증하고, 블로그 글 복사 기능을 PRO 로 유도

2. **블로그 자동 작성 + 유료 복사**  
   - 이유: 네이버 블로그 포스팅은 공인중개사의 필수 업무 → 자동화 도구로 대체 가능한 작업
   - 수익 모델: 
     - 무료 버전: 카드 생성만 가능 (블로그 글 작성은 제한)
     - PRO 버전 ($5/month): 블로그 글 복사, 10 개 매물까지 무제한

3. **재개발 분석 기능 (후순위)**  
   - 이유: 기술적 난이도 높고, 수익 효율성이 불명확 → MVP 단계에서 제외
   - 향후 확장 시 고려

## 3. 수익 효율성 지수 계산 (예상)

### 비용 구조 (1 인 기업 기준)
- API 비용: 블로그 자동 작성을 위해 Gemini 호출 (월 ~$50)
- 서버/호스팅: Vercel / Netlify 무료 티어 활용 가능
- 개발 시간: 기존 코드 기반 수정만 → 2 주 내 완료 예상

### 예상 매출 (첫 달)
- 카드 생성기 유입: 월 1,000 명 시니어 중개사
- 유료 전환율: 5% (~50 명) × $5 = $250/월
- 블로그 글 복사 수익: PRO 버전 가입자 30 명 × $5 = $150/월
- **총 예상 매출: ~$400/월**

### ROI (투자 대비 수익률)
- 개발 시간: 2 주 × 8 시간/일 × $50/hour = $800 기회비용
- 월 매출 $400 → 2 개월 내 투자 회수 가능
- **ROI 지수: +1.5**

## 4. 핵심 메시지와 유튜브 콘텐츠 연계 전략

### 주요 메시지 (CTA)
- "3 번 클릭으로 매물 카드 생성, 블로그 글 자동 작성"
- "지금 가입하세요 → 무료 체험 10 회"
- "PRO 플랜: 월 5 만원 (블로그 글 복사)"

### 유튜브 콘텐츠 방향성
- **시리즈명**: `공인중개사 시간 절약 가이드`

# 💰 가격 전략 및 번들 옵션 — 수익 효율성 지수 기반

## 1. 목표
공인중개사 결제 100건 달성을 위한 **가장 높은 ROI(투자 대비 수익) 를 보장하는 가격 모델**을 선정하고, 유튜브 콘텐츠의 CTA(Call to Action) 에 이를 반영하기 위한 핵심 메시지를 생성합니다.

## 2. 초기 가설: 번들 옵션 A/B/C 비교 (가정 데이터)
프로카드 2.0 의 핵심 기능: AI 매물 카드 생성 + 네이버 블로그 자동 작성 + 표시·광고법 컴플라이언스 엔진

| 번들 | 가격 (원/월) | 포함 기능 | 예상 월별 결제 건수 | LTV 추정치 | ROI 지수* |
|------|--------------|-----------|-------------------|------------|----------|
| **Basic** | 29,000 | 카드 생성 + 블로그 포스팅 (1 개 매물) | 450건 | 387,000원 | 1.34x |
| **Pro** | 49,000 | Basic + 5 개 매물 자동 분석 + CTA 문구 최적화 | 650건 | 321,500원 | 1.85x |
| **Business** | 79,000 | Pro + 블로그 상위 노출 가이드 (법전 기반) + 재개발 투자 전략 자료 | 400건 | 316,000원 | 2.15x |

* ROI 지수 = (LTV - 고객 획득 비용) / 고객 획득 비용 (CAC ≈ 8,000원 가정)

**가장 높은 수익 효율성:** Business 번들은 LTV 대비 CAC 가 가장 낮고, 재개발 투자 전략 자료는 공인중개사에게 실질적인 부가가치를 제공하여 장기 계약 유도에 유리합니다. 하지만 초기 진입 장벽이 높으므로 **Pro 번들이 첫 결제 유도용 가장 적합**합니다.

## 3. 핵심 메시지 (유튜브 콘텐츠용)
- **CTA 문구:** "프로판 49,000원 월정액으로 매물 분석 5 개 추가 받습니다."
- **부연 설명:** "기본형보다 2 만 원 더 지불하면 매월 AI 가 알아서 최적의 블로그 글을 작성해줍니다. 재개발 투자 자료도 제공됩니다. 지금 구독하고 체험해보세요."
