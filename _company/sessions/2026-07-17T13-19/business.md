# 💳 PayPal 개발자 환경 설정 가이드 (현빈용)

## 🎯 목표
'첫 결제 100건' 달성을 위한 PayPal 연동 준비. 샌드박스 모드로 테스트 후 라이브 모드로 전환.

---

## 🔑 Client ID 및 Secret 발급 절차

### 단계 1: PayPal Developer Dashboard 접속
```
https://developer.paypal.com/dashboard/applications/
```
- 로그인 (PayPal 개발자 계정 필요)
- **Apps & Credentials** 메뉴 클릭

### 단계 2: 새 앱 생성
1. **Create App** 버튼 클릭
2. **App Name:** `프로카드_결제시스템` 입력
3. **Sandbox Client ID/Secret:** 자동 생성됨 (테스트용)
4. **Live Mode:** 현재는 비활성화 (라이브 결제 불가)

### 단계 3: Live Mode 전환 준비 (실제 결제 전 필수!)
```
https://developer.paypal.com/dashboard/applications/live-mode/
```
- 앱에서 'Go live' 버튼 클릭
- **Live Client ID 및 Secret** 발급
- ⚠️ **라이브 환경 사용 시:**
  - 실제 카드 번호 필요
  - PayPal 수수료 발생 (2.9% + $0.30)
  - 법적 동의서 서명

---

## 🧪 샌드박스 vs 라이브 모드 비교

| 구분 | 샌드박스 | 라이브 |
|------|----------|---------|
| **사용 목적** | 개발/테스트 | 실제 결제 |
| **카드 번호** | 테스트용 (4242 4242...) | 실제 카드 |
| **수수료** | 무료 | 2.9% + $0.30 |
| **고객 데이터** | 가짜 | 진짜 |

### 🛡️ 샌드박스에서 라이브로 전환 시 체크리스트
- [ ] 모든 결제 트랜잭션이 정상적으로 처리됨 (최소 10 건 테스트)
- [ ] 환불/취소 플로우 검증 완료
- [ ] 고객 피싱 예방 가이드 배포 (예: "정품 PayPal 인증" 문구)

---

## 📦 라이브 환경 연동 코드 예시 (`server.ts` 수정 시 참고)

```typescript
// .env 파일에 라이브 토큰 저장
PAYPAL_CLIENT_ID=실제_라이브_Client_ID
PAYPAL_CLIENT_SECRET=실제_라이브_Secret
PAYPAL_MODE=live  // sandbox → live 로 변경

// 서버 시작 전 환경 변수 확인
console.log(`🚀 PayPal Mode: ${process.env.PAYPAL_MODE || 'sandbox'}`);
```

# 💰 '첫 결제 100건' 실행 마스터 플랜 (4 주 로드맵)

## 🎯 최종 목표

**목표:** 샌드박스 모드로 10 건 결제 성공
- [ ] PayPal 라이브 토큰 발급 및 `.env.local` 등록
- [ ] `server.ts`에서 실제 결제 처리 로직 검증 (샌드박스 테스트 카드 사용)
- [ ] **프로모션 전략 수립:** "초기 우대 할인 30%" (첫 10 건만)

**주요 액션:**
```bash
# Week 1 체크리스트
- [x] PayPal 앱 생성 및 라이브 토큰 발급
- [x] .env.local 에 PAYPAL_CLIENT_ID/SECRET 저장
- [ ] server.ts 에서 실제 결제 테스트 (테스트 카드: 4242 4242...)
- [ ] 마케팅 페이지에 '초대형 할인' 배너 추가
```

**예상 매출:** 0 원 (결제 실패/환불 테스트) → 30 만 원 (10 건 실제 결제)

---

### Week 2: 초기 고객 확보 & 리뷰 수집 (6/3 ~ 6/9)

  - 네이버 카페 '공인중개사' 그룹에 홍보글投放
  - 인스타그램/유튜브 쇼츠: "1 분 만에 매물카드 만들기" 리얼 후기
- [ ] **리뷰 유도:** 결제 후 자동 발송 이메일로 "후기 작성 시 다음 고객에게 5,000원 할인권 제공"

**주요 액션:**
```markdown
## Week 2 체크리스트
- [x] 마케팅 채널별 콘텐츠 배포 (네이버 카페/인스타그램)
- [ ] 고객 상담 채널 오픈 (카톡/전화)
- [ ] PayPal 결제 성공 후 자동 감사 메일 발송 (테스트 완료)
- [ ] 리뷰 수집 및 SSO (Social Proof) 확보
```

**예상 매출:** 120 만 원 (25 건 × 49,000원) + 75 만 원 (무료 체험판 포함) = **195 만 원**

---

### Week 3: 자동화 & 재구매 유인 전략 (6/10 ~ 6/16)
**목표:** 30 건 결제 달성 + 2 번 구매 고객 확보
- [ ] **자동화 도입:** 
  - PayPal 과 연동된 이메일 마케팅 자동화 (Mailchimp/Zoho)
  - "결제 완료 → 1 일 후 리뷰 요청 → 3 일 후 다음 번을 추천" 플로우 구축
- [ ] **재구매 유인:** "매달 새로운 매물카드 제작 시 추가 20% 할인" 프로모션

**주요 액션:**
```markdown
## Week 3 체크리스트
- [x] 이메일 자동화 플로우 설계 (결제 → 리뷰 → 다음 구매)
```
