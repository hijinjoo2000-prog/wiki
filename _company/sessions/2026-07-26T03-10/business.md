# 🎯 지식 저널 + 유료 컨설팅 수익화 모델 MVP 설계 (v0.1)

## 1. MVP 핵심 가설
- **가정**: 공인중개사 대상 '지역별 투자 분석 + 법전 해석' 콘텐츠는 유료 구독자(2~3 만원/월) 및 단일 컨설팅 주문(5~10 만원/건)으로 전환 가능.
- **검증 목표**: MVP 4 주 안에 최소 10 명 공인중개사 타겟으로 '무료 체험판' 제공 후 유료 전환율 5% 이상 달성 여부.

## 2. 제품 기능 정의 (MVP 범위)
| 모듈 | 기능 | 비용/기술 요구사항 |
|------|------|-------------------|
| **저널** | 공인중개사 전용 정보 게이트웨이 (지역별 재개발·법전 분석 등) | Static site + CMS (예: WordPress / Ghost) + RSS 피드 (무료 API) |
| **컨설팅** | '15 분 긴급 질문' 및 '맞춤 보고서' 주문형 서비스 | Calendly 연동 또는 자체 스케줄러 + Google Docs 템플릿 (무료) |
| **결제** | Stripe 또는 PayPal 결제 연동 (월정산) | 기존 개발팀(코다리) 의 안정화된 API 연동 스크립트 재사용 |

## 3. MVP 마일스톤 및 일정
- **W1**: 프로토타입 웹페이지 + 콘텐츠 5 편 발행 (현빈/Writer 협업)
- **W2**: 공인중개사 타겟 홍보 (LinkedIn / 업계 포럼) + 무료 체험판 오픈
- **W3~4**: 유료 전환 테스트 및 가격 전략 검증 (A/B 테스트: 월정액 vs 개별 주문)

## 4. Designer 협업 요청 사항
- **디자인 가이드라인**: 
  - 전문성 + 신뢰감 (블루/회색 계열, 세련된 타이포그래피)
  - 모바일 퍼스트 반응형 레이아웃
  - '무료 체험판' 유도 버튼 CTA 강조
- **기술 스택**: HTML/CSS + Tailwind 또는 React (디자인팀의 기존 기술栈과 호환성 확인 필요)

## 5. 콘텐츠 기획 초안
| 주제 | 내용 | 예상 조회수/전환율 |
|------|------|-------------------|
| '2026 년 서울 재개발 지역 투자 가이드' | 재개발 조합·법정사건 분석 + 예상 시세 | 1,000 회 이상 / 3% 유료 전환 |
| '공인중개사 법전 해석: 이자율 조정 신청 방법' | 실제 사례 기반 법률 해석 | 500 회 이상 / 5% 유료 전환 |
| '아파트 투자 시 세금 공제 전략' | 세무 관련 최신 정책 분석 | 800 회 이상 / 4% 유료 전환 |
