## 📊 프레임워크 개요

| 항목 | 내용 |
|------|------|
| **테스트 기간** | 4 주 (첫 주: 교육, 둘째 주~넷째 주: 실제 활용 측정) |
| **타겟 공인중개사** | 재개발 프로젝트에 관심 있는 60대 이상 시니어 (기술 거부감 낮음, ROI 민감도 높음) |
| **핵심 메시지** | "AI 가 매물 설명을 써주면 네이버 블로그 상위 노출 + 블로그 글 복사는 유료화. 지금 시작하면 재개발 투자 분석으로 추가 수익 확보." |
| **검증 KPI** | 1. 유료 전환율 (무료 → $29/월), 2. 평균 매물당 생성 수, 3. 재개발 니치 키워드 포함 비율, 4. 고객 지원 티켓 감소율 |

## 📖 Scene-by-Scene 상세 설계

### **SCENE 0: 오버레이 — "왜 지금 PROCARD 를 써야 하는가?" (15 초)**
| 요소 | 내용 |
|------|------|
| **시각** | 재개발 아파트 입지 지도 + 조합원 vs 일반 분양가 차이를 나타내는 그래프. 배경은 따뜻한 옐로우 톤. |
| **사운드** | "재개발 프로젝트, 당신의 다음 수익 기회입니다." (저음 효과음) |
| **CTA** | **"무료 체험 14 일 — 지금 시작하기"** (버튼 클릭 시 Pricing 페이지로 이동) |

### **SCENE 1: 문제 제기 — "재개발 정보 분석은 얼마나 번거로운가?" (30 초)**
| 요소 | 내용 |
|------|------|
| **시각** | 60 대 중개사가 종이를 펼쳐보며 고민하는 모습. 화면에 "5 분, 24 장의 서류 정리" 텍스트 오버레이. |
| **사운드** | "매물 설명 작성부터 블로그 포스팅까지, 하루 3 시간 이상 투자하세요." (타이핑 소리) |
| **CTA** | **"AI 가 대신해줄까요?"** → 다음 장면으로 전환 |

### **SCENE 2: 해결책 제시 — "PROCARD AI 매물 카드를 만들면" (45 초)**
| 요소 | 내용 |
|------|------|
| **시각** | PROCARD 인터페이스에서 자유 서술형 설명을 입력하면 자동으로 `PropertyListing` 스키마에 맞는 JSON 이 생성되고, 이를 기반으로 카드 템플릿이 적용되는 애니메이션. |
| **사운드** | "단 30 초 만에 매물 설명 정리 → 네이버 블로그 글 복사 → 인스타 카드 PNG 저장." (스위치 클릭 효과음) |
| **CTA** | **"무료로 체험해보세요"** (버튼 클릭 시 'Sign Up' 페이지로 이동) |

### **SCENE 3: 가격 모델 공개 — "하이브리드 요금제, 왜 지금인가?" (40 초)**
| 요소 | 내용 |
|------|------|
| **시각** | Pricing 페이지 스냅샷. 월 구독 $29 (기본) + 매물당 $3~$10 옵션 표시. 무료 플랜과 비교 표. |
| **사운드** | "무료로 시작하세요, 필요할 때만 유료화. 재개발 투자 분석 모듈은 PRO 버전 전용입니다." (카운트다운 효과음) |
| **CTA** | **"지금 결제하기"** → 'Billing' 페이지로 이동 (PayPal 통합 예정) |

### **SCENE 4: ROI 강조 — "1 개 매물당 $5 비용으로 얼마나 벌 수 있는가?" (30 초)**
| 요소 | 내용 |
|------|------|
| **시각** | 재개발 아파트 투자 분석 결과를 보여주는 PROCARD 대시보드. 조합원 분양 vs 일반 분양 차이를 시각화한 그래프. |
| **사운드** | "1 개 매물당 $5 비용으로 네이버 블로그 상위 노출 + 블로그 글 복사 수익 3 배 이상." (통화기 효과음) |
| **CTA** | **"ROI 계산기 무료 사용"** → ROI Calculator 페이지로 이동 (현재는 Placeholder 데이터 표시) |

### **SCENE 5: 사회적 증명 — "실제 공인중개사들이 말함" (40 초)**
| 요소 | 내용 |
|------|------|
| **시각** | 60 대 중개사의 실제 인터뷰 클립 (배경은 사무실). 화면에 "PROCARD 사용 후 매물 생성 시간 5 분 단축, 블로그 글 복사 수익 3 배 증가." 텍스트 오버레이. |
| **사운드** | "저는 70 세 중개사입니다. PROCARD 를 쓰니까 이제 하루 1 시간만 투자해도 됩니다." (스마트폰 터치 효과음) |
| **CTA** | **"실제 리뷰 보기"** → Testimonials 페이지로 이동 |

### **SCENE 6: 재개발 니치 키워드 — "PROCARD 에서 '재개발'을 어떻게 활용하나?" (50 초)**
| 요소 | 내용 |
|------|------|
| **시각** | PROCARD 대시보드에서 '재개발 투자 분석' 탭 클릭 시, 조합원 vs 일반 분양가 차이, 비례율, 이주비 대출 정보 자동 분석되는 애니메이션. |
| **사운드** | "PROCARD 에서 재개발 니치 키워드를 자동으로 생성합니다. 네이버 블로그 상위 노출을 위한 최적화된 키워드입니다." (타이핑 소리) |
| **CTA** | **"무료로 체험해보세요"** → 'Sign Up' 페이지로 이동 |

### **SCENE 7: 마무리 — "지금 시작하는 것이 가장 좋습니다" (30 초)**
| 요소 | 내용 |
|------|------|
| **시각** | PROCARD 로고 + Slogan ("공인중개사, AI 로 수익화하세요") + PayPal 결제 버튼. |
| **사운드** | "무료 체험 14 일 — 지금 시작하면 재개발 투자 분석으로 추가 수익 확보." (클로징 효과음) |
| **CTA** | **"지금 무료로 체험하기"** → 'Sign Up' 페이지로 이동 |

## 📈 가격 모델 및 번들 옵션 (MVP 검증용)

### **옵션 1: 월 구독 ($29/월)**
- 기본 PROCARD AI 매물 카드 생성 + 네이버 블로그 글 복사
- 재개발 투자 분석 모듈은 제외 (PRO 버전 전용)
- **적합 대상**: 초기 사용자에게 무료 체험 → 유료 전환 유도

### **옵션 2: 매물당 비용 ($3~$10/매물)**
- 매물당 $3 기본 요금 + 고급 기능 ($5~$10 추가) 적용
- 재개발 투자 분석, 고급 키워드 최적화 포함 (PRO 버전)
- **적합 대상**: 대량 매물을 생성하는 중개사

### **옵션 3: 하이브리드 ($29/월 구독 + 매물당 $3)**
- 월 구독 기본 기능 + 매물당 추가 비용
- 재개발 투자 분석 모듈은 PRO 버전 전용
- **적합 대상**: 기존 사용자에게 추가 수익화 유도
