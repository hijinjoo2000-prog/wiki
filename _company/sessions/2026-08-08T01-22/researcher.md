### 1. A/B 테스트 데이터 확보를 위한 즉각적인 데이터 수집 방안 (Action Plan)

실제 데이터를 확보하기 위해서는 **데이터 수집 파이프라인(코다리)**과 **사용자 인터페이스(디자이너)**의 연동을 최우선으로 보장해야 합니다. 현재 상황에서 가장 가치 있는 단일 작업은 '데이터 수집 환경의 안정화 및 측정 지표 정의'에 집중하는 것입니다.

#### 1.1. 데이터 수집 전략: 시스템 기반 자동 로깅 (권장)
수동 데이터 입력은 오류 발생 가능성이 높으므로, **Design-to-Code Contract**에 따라 설계된 자동 로깅 시스템의 실행 가능성을 검증하고 이를 활용해야 합니다.

*   **핵심:** A/B 테스트 참여 과정에서 발생하는 모든 이벤트(인지 부하 점수 측정 결과, 사용자 입력 데이터, 최종 결제 여부)를 **실시간으로 로그**하도록 시스템을 확정합니다.
*   **세부 방안:**
    1.  **지표 정의 확정:** `sessions/2026-08-07T10-46/researcher_efficiency_data_for_checklist.py`에서 정의된 **Price\_Efficiency\_Label(PEI)** 및 인지 부하 점수(`Cognitive Load Score`)를 시스템이 정확히 수집하도록 데이터 모델을 최종 확정합니다.
    2.  **로그 연동 확인:** 코다리가 준비 중인 A/B 테스트 데이터 로깅 시스템과 실제 UI 컴포넌트(Designer가 설계한 모듈) 간의 API 통신 및 데이터 포맷 일치를 **MVP Phase 1 환경에서 즉시 검증**합니다.
    3.  **데이터 흐름 검증:** Control 그룹과 Variant 그룹이 서로 다른 지표를 정확히 기록하고, 이 데이터가 `cleaned_market_data.parquet` 또는 지정된 로그 파일에 올바르게 집계되는지 **시스템 로그(`sessions/2026-08-08T01-07/developer.md`)**를 통해 실시간으로 확인합니다.

#### 1.2. 보조 수집 방안: 초기 데이터 검증 (Fallback)
자동 로깅 시스템이 구축되는 동안, 최소한의 통계적 유의미성(Significance)을 검증하기 위해 기존에 확보된 데이터를 활용합니다.

*   **활용 자료:** `target_audience.csv` 파일에 명시된 타겟 세그먼트별 초기 반응 데이터를 A/B 테스트 그룹과 매칭하여, 시스템 로깅 결과와 **초기 상관관계의 일치 여부**를 교차 검증하는 데 사용합니다.

### 2. 데이터 로깅 시스템 실행 가능성 검토 (Feasibility Review)

현재 데이터 로깅 시스템은 **기술적 통합(Design-to-Code Contract)**과 **LLM 안정성 확보(FTRC 연동)**라는 두 축을 중심으로 설계되었습니다. 이 시스템의 실행 가능성은 매우 높으나, 다음 세 가지 조건이 충족되어야 합니다.

| 검토 항목 | 현황 분석 | 실행 가능성 평가 | 필요한 조치 (Next Step) |
| :--- | :--- | :--- | :--- |
| **기술 통합 안정성** | Designer의 UI/UX 디자인과 코다리의 데이터 로깅 모듈 간의 연결이 핵심입니다. | **높음** | MVP 환경에서 실제 데이터 흐름(Input $\rightarrow$ Log)을 100% 시뮬레이션하여 오류 지점을 사전에 제거해야 합니다. |
| **LLM 실패 방지 연동** | LLM 호출 실패율(FTRC 1% 미만 유지 목표)을 데이터 로깅에 연결하는 것이 핵심입니다. | **중간** | FTRC 메커니즘이 데이터 기록 중단이나 오류를 유발하지 않도록, 예외 처리 로직을 최종적으로 통합 검증해야 합니다. |
| **데이터 무결성 (Integrity)** | 수집된 데이터가 재현 가능하고 객관적이어야 합니다. | **높음** | 모든 로그는 타임스탬프와 함께 원본 소스(사용자 입력)를 참조하도록 설계되어야 하며, 이 지침을 코다리가 구현해야 합니다. |

**결론:** 시스템은 이론적으로 실행 가능합니다. 데이터 확보의 성공 여부는 이제 **"시스템이 설정한 대로 정확하게 데이터를 기록하는가?"**라는 기술적 검증에 달려 있습니다.
