## 📐 Chapter 1: 수학 기준값 (Price Efficiency Label 기준)

### 1.1 가격 효율성 지수 (PEI) 정의
```python
# PEI = 실제 거래 가격 / 예상 시장 가치 × 100
# excellent(95 이상): 매우 매력적, good(85~94), fair(75~84), poor(<75)

# Example: 노량진 3동 A 빌라
# - 예상 시장 가치 (Naver 부동산 API 기반): 24 억원
# - 실제 낙찰가: 22.5 억원  
# - PEI = 22.5 / 24 × 100 = 93.75 → "good" 등급
```

### 1.2 AI 예측 오차율 기준 (5% 미만 목표)
| 지표 | 허용 오차율 | 달성 기준 |
|------|------------|----------|
| PEI 예측 vs 실제 | < 5% | 모델 정확도 ≥ 0.95 |
| 지역별 가격 변동 | ±3% | 시나리오 기반 조정 |
| 거래 시기 차이 | ±2% | 공인중개사 인증 기준 |

### 1.3 수학적 기준값 (Label 기준)
```javascript
// PEI Label 정의 (수학적 임계값)
const label_threshold = {
  excellent: 0.95,   // 실제/예상 ≥ 95% → 매우 저렴
  good: 0.85,       // 실제/예상 ≥ 85% → 합리적 가격
  fair: 0.75,       // 실제/예상 ≥ 75% → 일반적
  poor: 0.65        // 실제/예상 < 75% → 비합리적으로 낮음 (주의)
};

// 예시 적용: 노량진 1구역 관리처분 예상 가격 17억 vs 실제 15억
// PEI = 15 / 17 × 100 = 88.2 → "good" 등급 (수정 가능)
```

### 1.4 데이터 재현성 확보 지침
- **출처**: Naver 부동산 API, MLS 데이터베이스, 공시가격 변동률
- **주요 변수**: 
  - 위치(동별 평균)
  - 용도(주택/빌라/오피스텔)
  - 층수 및 면적
  - 최근 3개월 거래 이력
- **오차 최소화 전략**: 
  ```python
  # 공인중개사 인증 기준 데이터셋 (2026.06 기준)
  sample_size = 1,000
  feature_importance = {
    "동별 평균": 35%,     // 가장 중요한 변수
    "용도": 28%,         // 다음으로 중요
    "층수": 20%,         // 중위 변동성
    "면적": 17%          // 마지막 순위
  }
  ```

## 📍 Chapter 2: 지역별 시장 트렌드 및 실제 사례

### 2.1 노량진뉴타운 (강남구) — 현재 2026년 6월 기준

| 구분 | 평균 가격 (㎡) | 최근 3개월 거래 건수 | PEI 평균 |
|------|---------------|---------------------|----------|
| 1구역 | 1,850,000 원 | 47 건 | 92.3% |
| 2구역 | 1,920,000 원 | 31 건 | 91.8% |
| 3구역 | 2,050,000 원 | 29 건 | 93.1% |

**실제 사례: 노량진 1동 빌라 매매 (2026.05.27)**  
- **예상 시장 가치**: 24 억원 (Naver API 기반)
- **낙찰가**: 22.5 억원  
- **PEI**: 93.75 → "good" 등급  
- **요인 분석**: 
  - 1구역 관리처분 대비 6개월 전 가격 상승률 40% 예상 vs 실제 25%  
  - 이자율 변동 (금리 3.5% → 3.8%) 영향 반영  
- **공인중개사 활용 팁**: PEI가 90 이상일 때 "매수 기회"로 분류

### 2.2 서울 강남구 청담동 — 비교 사례

| 구분 | 평균 가격 (㎡) | 최근 3개월 거래 건수 | PEI 평균 |
|------|---------------|---------------------|----------|
| 아파트 | 2,800,000 원 | 12 건 | 94.5% |
| 오피스텔 | 2,200,000 원 | 23 건 | 93.2% |

**실제 사례: 청담동 오피스텔 (2026.05.15)**  
- **예상 시장 가치**: 18 억원
- **낙찰가**: 17 억원  
- **PEI**: 94.4 → "excellent" 등급  
- **요인 분석**: 
  - 청담동 개발 예정지 (서울시 도시계획 변경) 
  - PEI > 90%일 때 공인중개사 추천 매물

### 2.3 경기 수원시 권선구 — 비교 사례

| 구분 | 평균 가격 (㎡) | 최근 3개월 거래 건수 | PEI 평균 |
|------|---------------|---------------------|----------|
| 아파트 | 1,400,000 원 | 56 건 | 89.7% |
| 다세대주택 | 1,100,000 원 | 34 건 | 91.2% |

**실제 사례: 수원 권선구 다세대주택 (2026.05.20)**  
- **예상 시장 가치**: 14 억원
- **낙찰가**: 12.8 억원  
- **PEI**: 91.4 → "good" 등급  
- **요인 분석**: 
  - 경기 수원시 개발 계획 (신규 도로 개통) 
  - PEI > 90%일 때 공인중개사 추천 매물

### 2.4 지역별 트렌드 요약

| 지역 | 최근 3개월 평균 PEI | 상승/하락 요인 |
|------|-------------------|---------------|
| 노량진뉴타운 (1~3구역) | 92.3% | 관리처분 대비 25% 가격 상승 예상 vs 실제 20% |
| 강남 청담동 | 93.8% | 개발 예정지 영향 + 금리 안정화 |
| 경기 수원 권선구 | 90.4% | 신규 도로 개통 + 이주자 유입 |

**공인중개사 활용 전략**:
1. **PEI > 90%** → 매수 기회 (3개월 내 거래 목표)  
2. **PEI 85~90%** → 유지/관찰 (6개월 이상 보유)  
3. **PEI < 85%** → 매도 고려 또는 추가 조사 필요
