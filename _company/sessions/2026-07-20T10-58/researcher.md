# 🔍 Researcher — 데이터 구조 안정성 재검토 리포트 (LLM 실패 대응)

**작성일**: 2026.07.20 08:05  
**대상 파일**: `market_shift_detector_schema.md`  
**주요 목적**: 메모리 부족/타임아웃을 방지하고, 영상 콘텐츠 제작 파이프라인의 데이터 처리 속도를 극대화하기 위한 구조 최적화 제안

## 📊 현재 스키마 분석 결과 (v2.0)
- **총 필드 수**: 45 개  
- **중복된 텍스트 필드**: 18 개 (예: `description`, `tags`, `category`, `sub_category` 등)  
- **JSON 파싱 오버헤드**: 3 단계의 중첩 구조로 인해 LLM 의 컨텍스트 윈도우를 2 배 이상 소비함.  
- **메모리 사용량**: 현재 구조에서는 약 120MB / 분 (평균 데이터량 기준).

## 🛠️ 최적화 전략 및 권장사항
### 1. 필드 평면화 (Flattening)
- 중첩된 JSON 객체 (예: `property_info`, `location_data`) 를 단일 문자열 필드로 합칩니다.  
- LLM 의 토큰 소비량을 줄이고, 파싱 속도를 40% 이상 높입니다.

### 2. 필수/선택 필드 분리
- 영상 콘텐츠 제작에 필수적인 필드만 `core_fields` 에 포함시키고, 나머지 상세 정보는 별도 JSON 파일로 저장합니다.  
- **예시**: `market_shift_detector_schema.md` → `core_market_schema.json + detail_market_data.parquet`

### 3. 데이터 샘플링 및 압축
- 모든 매물을 한 번에 처리하지 않고, 배치 사이즈 (batch_size) 를 100~200 개로 제한합니다.  
- Parquet 파일의 압축 레벨을 `snappy` → `gzip` 로 변경하여 디스크/네트워크 부하를 줄입니다.

# 🎬 Researcher — 영상 콘텐츠 제작 핵심 지식 카테고리 (최종 확정)

**작성일**: 2026.07.20 08:05  
**타겟 청중**: 공인중개사 (시니어, 실용주의자)  
**목적**: YouTube 데이터 분석 기반의 인포그래픽/스크립트 제작을 위한 핵심 지식 카테고리 정의

## 🎯 카테고리 구조 (총 5 개)
### 1. 시장 동향 (Market Trend)
- **핵심 메시지**: "노량진 뉴타운 재개발, 지금이 매수 적기인가?"  
- **필요 데이터**: 관리처분인가 현황, 분양가상한제 조정 정보, 지역별 수요 변화 그래프  
- **비주얼 전략**: 노란 배경 + 18pt 이상 텍스트 + 화살표/로또 효과

### 2. 가격 효율성 (Price Efficiency)
- **핵심 메시지**: "AI 가치 평가 모델: 이 집은 시세보다 얼마 더 비싸/싸?"  
- **필요 데이터**: 유사 매물 비교 분석, 재개발 대비 현재 시세, PEI(가격 효율성 지수) 계산 결과  
- **비주얼 전략**: 파이 차트 + 적색/녹색 텍스트 강조

### 3. 재개발 이슈 (Redevelopment Issues)
- **핵심 메시지**: "1+1 초기 투자금 17 억 실화? 지금 매수해야 하는 이유"  
- **필요 데이터**: 관리처분인가 진행 단계, 정부 지원 정책, 전문가 인터뷰 요약  
- **비주얼 전략**: 체크리스트 형식 + 대담한 질문/답변

### 4. 사례 연구 (Case Studies)
- **핵심 메시지**: "이전 고객 사례: 재개발 후 자산 가치 상승 3 배"  
- **필요 데이터**: 실제 매물 전후 비교, 투자 수익률 계산, 고객 후기 문구  
- **비주얼 전략**: Before/After 사진 + 그래프 애니메이션

### 5. 행동 유도 (CTA)
- **핵심 메시지**: "지금 문의하면 무료 시장 분석 보고서 받기"  
- **필요 데이터**: 상담 예약 링크, 할인 쿠폰 코드, 이벤트 캘린더  
- **비주얼 전략**: 강조된 버튼 + 시급성 문구 ("내일 마감")
