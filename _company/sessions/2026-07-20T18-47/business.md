# 🎯 MVP 최종 비즈니스 목표 및 핵심 성과 지표 (KPI) 명세서

**작성일:** 2026. 7. 21  
**수신자:** Designer, Developer, Writer  
**참조 파일:** `business_kpi_target.md`, `pricing_strategy.md`

## 1. 개요

프로카드 2.0 의 MVP 프로토타입 제작 및 출시를 위한 최종 비즈니스 목표와 핵심 성과 지표 (KPI) 를 정의합니다. 이 명세서는 웹 페이지의 UI/UX, 가격 표시 방식, 결제 유도 흐름을 구체적으로 결정하는 기준이 됩니다.

## 2. 핵심 가정 및 제약조건

- **타겟 고객:** 공인중개사 (60 대 이상 시니어 중심)
- **사용 환경:** 데스크톱 (사무실 PC), 태블릿 (현장 방문시)
- **결제 수단:** 한국 내 신용카드/가상계좌 (PayPal 도우미 데이터 참조, 국내 결제 게이트웨이 필요)
- **라이선스:** Google AI Studio API (Gemini 2.5 Flash)

## 3. 최종 비즈니스 목표 (MVP 출시 기준)

### 3.1 주요 목표
**"웹 페이지 프로토타입이 실제 결제 전환을 유도하는 검증 가능한 MVP 가 된다."**

- **결제 전환율 목표:** 방문자 대비 **최소 2%** 이상 (업계 평균보다 낮음, 하지만 시니어 타겟은 고려)
- **평균 결제 금액 (ARPPU):** $49.80 / 월 (구독 $29 + 매물당 $15 avg × 1 개매물)
- **월 구독 유지율:** 30 일 이상 **최소 60%** (시니어 고객층의 이탈 방지를 위해 쉬운 결제/해지 정책)

### 3.2 부수적 목표
- **브랜드 인지도:** 공인중개사 커뮤니티(카카오톡 오픈채팅, 블로그) 에서 "프로카드 AI" 검색 시 상단 노출
- **네트워킹 효과:** 사용자 간 추천 (Referral) 을 통해 신규 유입을 30% 이상 확보

## 4. 핵심 성과 지표 (KPI) 및 정의

### 4.1 고객 획득 비용 (CAC): $70 이하
**정의:** 한 명의 활성 구독자 (월 구독료 $29 이상 납부) 를 얻는 데 드는 총 마케팅/개발 비용.

- **성공 기준:** $65 미만 목표 (3 개월 내 달성)
- **구성 요소:**
  - 개발 인건비 (MVP 제작 기간 4 주 × 팀원 수)
  - 구글 AI API 비용 (연간 $1,000 이내)
  - 초기 마케팅/홍보 비용 (블로그 광고 등 $500)
  - 서버 호스팅 비용 (Vercel/Netlify 무료 티어 활용)

### 4.2 고객 생애 가치 (LTV): $180 이상
**정의:** 한 명의 구독자가 평균적으로 지불하는 총 수익 (구독료 + 매물당 비용).

- **성공 기준:** $195 이상 목표 (6 개월 내 달성)
- **구성 요소:**
  - 월 구독료: $29 × 6 개월 = $174
  - 평균 매물당 수익: $1 × 3 매물 = $3
  - 총: $177

### 4.3 결제 전환율 (Conversion Rate): 2% 이상
**정의:** 웹 페이지 방문자 중 실제 구독을 시작하는 비율.

- **성공 기준:** 2.5% 목표
- **측정 방법:** Google Analytics 4 (GA4) 또는 시니어 타겟에 맞춘 간단한 추적 스크립트

### 4.4 월간 활성 사용자 (MAU): 100 명 이상
**정의:** 한 달 동안 적어도 한 번 결제한 구독자 수.

- **성공 기준:** 3 개월 내에 100 명 달성
- **목표:** 결제 100 건 목표의 전제 조건 (1 명당 평균 2 매물 처리 시 50 건)

### 4.5 월간 매출 (MRR): $3,000 이상
**정의:** 한 달 동안 발생한 총 구독료 수익.

- **성공 기준:** $3,500 목표
- **구성 요소:** 100 명 × $29 = $2,900 + 매물당 수익 $500 = $3,400

## 5. 가격 전략 및 번들 옵션

### 5.1 기본 요금제 (Starter)
- **가격:** 월 $29 (한국 원화로 약 45,000 원)
- **기능:**
  - AI 기반 매물 카드 생성 (무제한)
  - 네이버 블로그 자동 포스팅 (기본 템플릿)
  - 모바일 최적화 웹 뷰어

### 5.2 프리미엄 요금제 (Professional) — 목표는 이 부분
- **가격:** 월 $49 (한국 원화로 약 70,000 원)
- **기능:**
  - AI 기반 매물 카드 생성 (무제한 + 고급 템플릿)
  - 네이버 블로그 자동 포스팅 (고급 레이아웃, 이미지 최적화)
  - YouTube 영상 스크립트 자동 작성
  - 경쟁사 대비 3 배 빠른 처리 속도

### 5.3 기업 요금제 (Enterprise) — 향후 확장 고려
- **가격:** 월 $99 (한국 원화로 약 140,000 원)
- **기능:**
  - 모든 기능 + API 접근 권한
  - 맞춤형 로고/브랜드 적용
  - 전용 고객 지원

## 6. 웹 페이지 프로토타입 제작 요구사항

### 6.1 UI/UX 지침
- **글자 크기:** 최소 24px (시니어 친화적)
- **이모지 사용:** 모든 주요 기능 설명에 이모지를 포함
- **색상 테마:** 흰 배경 + 고대비 텍스트 (검정/짙은 회색)
- **플로우:** 클릭 → 입력 → 생성 → 저장 → 공유 (단순한 4 단계)

### 6.2 가격표 컴포넌트 (`PricingTable`)
```jsx
// 예시 구조
<div className="pricing-table">
  <div className="card starter">
    <h3>Starter</h3>
    <p className="price">$29/월</p>
    <ul>
      <li>AI 매물 카드 무제한</li>
      <li>네이버 블로그 자동 포스팅</li>
    </ul>
  </div>
  <div className="card professional">
    <h3>Professional</h3>
    <p className="price">$49/월</p>
    <ul>
      <li>고급 템플릿 + YouTube 스크립트</li>
      <li>경쟁사 대비 3 배 빠른 처리</li>
    </ul>
    <button>지금 시작하기</button> // 주요 CTA 버튼
  </div>
</div>
```

### 6.3 결제 유도 흐름
1. **무료 체험:** 첫 3 개월 무료 (CAC 절감)
2. **업그레이드 유도:** 웹 뷰어에서 "프로 기능을 사용하려면 업그레이드하세요" 알림
3. **검증된 UX:** 시니어 타겟에 맞춘 명확한 버튼 라벨 ("지금 구독하기", "무료 체험 시작")
