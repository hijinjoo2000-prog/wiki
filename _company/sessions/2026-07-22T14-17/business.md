# 📄 최종 실행 계획 보고서 (핵심 KPI & 수익화 로드맵)

## 1. 핵심 KPI (공인중개사 결제 100건 목표 달성을 위한 지표)

### 🎯 Primary KPI (정량적 목표)
| 지표 | 목표치 | 측정 주기 | 책임 에이전트 |
|------|--------|-----------|---------------|
| **결제 건수** | 100 건/월 | 일일 추적 | 현빈 + 영숙 |
| **평균 결제 전환율** | ≥ 3.5% (방문 대비) | 주간 | 코다리 |
| **프로판 (PRO) 고객 수** | 20 명/월 | 월말 | 디자이너 + 현빈 |

### 📈 Secondary KPI (질적 지표)
- **NPS (Net Promoter Score)**: ≥ 50 점 (시니어 중개사 타겟)
- **매물 카드 생성 건수**: ≥ 1,000 개/월 (활성 사용량)
- **블로그 포스팅 자동화율**: ≥ 80% (PRO 전용 기능 활용도)

---

## 2. 수익화 단계별 로드맵 (가격 전략 기반)

### 🚀 단계 1: 초기 진입 (Starter, 1~3 개월)
**목표**: 시장 점유율 확보 및 데이터 수집  
**가격**: 무료 (기본형 + 제한된 AI 기능)  
**KPI**: 가입자 수 ≥ 200 명, 매물 카드 생성 건수 ≥ 500 개/일

- **전략**: 무료 버전으로 시니어 중개사들의 진입 장벽을 낮춤
- **기술적 제약 대응**: LLM 호출 실패 시 오프라인 템플릿(프린트) 기능 강화

### 🚀 단계 2: 프리미엄 전환 (Pro, 3~6 개월)  
**목표**: 수익화 시작 및 브랜드 신뢰도 구축  
**가격**: 월 19,800 원 (PRO 버전)  
**KPI**: PRO 고객 ≥ 15 명, 결제 전환율 ≥ 2.5%

- **전략**: 자동 블로그 포스팅, AI 매물 분석 등 고급 기능 유료화
- **기술적 제약 대응**: LLM 실패 시 로컬 API(예: Ollama) 연동으로 비용 절감

### 🚀 단계 3: SaaS 확장 (Enterprise, 6 개월 이상)  
**목표**: 대규모 중개사 사무所向 확장  
**가격**: 월 49,800 원 (사무소 단위 라이선스)  
**KPI**: Enterprise 고객 ≥ 5 곳, 매출 ≥ 1 억/년

- **전략**: 오프라인 분석 엔진(재개발 투자 전략 등) 추가
- **기술적 제약 대응**: 하이브리드 클라우드 + 로컬 실행 지원

---

## 3. LLM 호출 실패 시 기술적 제약을 수익화 전략에 반영한 내용

### 🔍 영향 분석 및 대응 방안
| 문제 | 영향 | 수익화 전략 수정 |
|------|------|------------------|
| **비용 증가** | AI 가 필요한 기능 제한 → 인건비 상승 | 오프라인 템플릿(프린트) 기능 강화, 로컬 API 연동 |
| **품질 저하** | 자동 콘텐츠 생성의 정확도 감소 → 이탈 가능성 ↑ | PRO 버전에는 고급 LLM (예: 40B 파라미터) 예약, 무료 버전은 기본 모델만 사용 |
| **기능 축소** | 고비용 LLM 필요 기능 제한 → 사용자 불만 | 유료 기능으로 전환(블로그 포스팅 자동화), 오프라인 대체 기능 개발 |

### 💡 기술적 제약 반영된 수익화 전략
1. **가격 차등화**: 
   - Starter: 무료 (기본 템플릿, 오프라인 모드 우선)
   - Pro: 19,800 원/월 (고급 LLM + 로컬 API 지원)
   - Enterprise: 49,800 원/월 (하이브리드 클라우드 + 데이터 분석 도구)

2. **기능 게이트웨이**: 
   - AI 자동 블로그 포스팅 → PRO 전용 (기술적 제약 시 수동 모드 제공)
   - 매물 분석 → Starter 에는 요약 기능만, Pro 에는 심층 분석 (오프라인 대체 포함)

3. **로컬 실행 옵션**: 
   - Ollama/LM Studio 연동 지원 (무료 버전에도 가능)
   - 로컬 API 호출 시 비용 절감 효과 강조 (PRO 고객에게 무료 업그레이드 제공)
