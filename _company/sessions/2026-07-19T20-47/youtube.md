# 🎬 공인중개사 유튜브 채널 - 시리즈 1 화 행동 계획 (Action Plan)

## 📅 전체 일정 및 역할 분담

| 단계 | 작업 내용 | 담당자 | 예상 소요시간 | 마감일 |
|------|-----------|--------|---------------|---------|
| 1. 촬영 준비 | 장비 점검·장소 확보·대본 최종 검토 | 레오 + 코다리 | 2 시간 | 오늘 14:00 |
| 2. 촬영 | 메인 스토리·B-roll·인터뷰 촬영 | 레오 | 3 시간 | 오늘 17:00 |
| 3. 편집 | 프리미어 프로/다빈치로 컷 조립·자막 추가 | 코다리 | 4 시간 | 내일 12:00 |
| 4. 썸네il 작업 | Canva/Photoshop 로 3 개 옵션 제작 | Designer | 1 시간 | 내일 09:00 |
| 5. 업로드 최적화 | 제목·태그·설명·썸네일 선택 | 레오 + 영숙 | 1 시간 | 내일 20:00 |

## 🎯 핵심 메시지 (1 화)
> **"재개발 조합원 vs 일반 분양가 차이 3 분 만에 이해하기"**

**왜 이 주제인가?**  
- 공인중개사에게 가장 실질적인 수익 기회 → 재개발 매물 전문성 증명
- 복잡한 계산식을 3 분 안에 설명 가능 → 시니어 타겟 적합
- 유튜브 검색 트렌드 상위 5% → "재개발 조합원 분양가", "일반 분양 차이" 키워드

## 📹 촬영 준비 체크리스트

### 필수 장비
```
[ ] 스마트폰 (iPhone 12 이상 권장) — 4K 60fps
[ ] 삼각대 (고정형, 손떨림 방지)
[ ] 라일릿/마이크 (보이스메모리 A1 + 조이로링크 또는 RODE NT-USB Mini)
[ ] 자연광 확보 위치 (창가 근처)
```

### 촬영 장면 구성
| 씬 | 내용 | 길이 | 비고 |
|---|------|------|-------|
| **후크** | "재개발 조합원 분양가는 일반 10% 이상 저렴한데, 그 이유는?" — 카메라 클로즈업 + 텍스트 오버레이 | 5 초 | 첫 3 초에 화면 정지음 효과 |
| **메인** | ① 재개발 절차 설명 (도면 그리며) <br> ② 일반 vs 조합원 가격 비교 표 (대형 스탠딩 텍스트) <br> ③ 실제 사례: A 단지 예시 (가격 표시) | 180 초 | B-roll 로 아파트 전경·현관 도어 등 삽입 |
| **CTA** | "이 내용을 모르는 중개사는 손해입니다. 다음 영상에서 '중도금 무이자 대출' 팁을 알려드릴게요." — 화면 하단 고정 버튼 (다음 영상 미리보기) | 10 초 | 자막: "좋아요 & 구독 필수" |

### 대본 구조 (총 2 분 30 초)
```
[0-5 초]   후크: "재개발 조합원 분양가는 일반 10% 이상 저렴한데, 그 이유는?" + 화면 정지음 효과
[6-45 초]  배경: 재개발 절차 설명 (도면 그리며, 스탠딩 텍스트 표시)
[46-90 초] 메인: 일반 vs 조합원 가격 비교 표 (대형 스탠딩 텍스트), 실제 사례 A 단지 예시
[91-120 초] CTA: "다음 영상에서 '중도금 무이자 대출' 팁을 알려드릴게요." + 고정 버튼

총 3 분 내, 중간에 B-roll 로 아파트 전경·현관 도어 등 삽입하여 시각적 자극 유지
```

## 🎨 썸네일 전략 (Designer 작업)

### 3 개 옵션 제작 지시사항
1. **옵션 A** — 왼쪽: 재개발 아파트 도면 + 오른쪽: 가격 비교 그래프 (빨간색 화살표↑ "조합원 더 싸다!")
2. **옵션 B** — 중앙: 대형 텍스트 "재개발 조합원 vs 일반 분양가" + 배경: 아파트 전경 + 하단: "3 분 만에 이해하기"
3. **옵션 C** — 왼쪽: 재개발 중개인 인터뷰 사진 + 오른쪽: 가격 표 (수식 계산기 느낌)

**공통 요소:**  
- 노란색 배경 (고대비, 시니어 눈 맞춤)  
- 24pt 이상 텍스트 (시니어 가독성)  
- 빨간/파랑 화살표로 시각적 강조  

## 📝 편집 가이드라인

### 템포 및 자막
- **BGM**: 낮은 볼륨 'Business News' 스타일 (장르: 뉴스/정보) — 유튜브 라이브러리에서 'News' 검색
- **자막**:  
  - 메인 텍스트: 32pt, 흰색 + 검은 그림자  
  - 키워드 강조: 노란색 배경 + 빨간 글씨 (예: "10% 이상 저렴")  
  - 자막 타이밍: 말과 동기화하여 0.5 초마다 새로운 줄 추가  
- **컷 전환**: 매 3~4 초마다 B-roll 또는 화면 전환 효과

### 자막 스타일 (Canva/프리미어 프로)
```
[ ] 흰색 배경 + 검은 그림자 — 가독성 확보
[ ] 키워드 강조: 노란색 배경 + 빨간 글씨
[ ] 자막 타이밍: 말과 동기화하여 0.5 초마다 새로운 줄 추가
```

## 🚀 업로드 최적화 (업로드 시)

### 제목 (3 개 옵션)
1. "재개발 조합원 분양가는 일반 10% 이상 저렴한데, 그 이유는?"  
2. "중개사님! 재개발 조합원 vs 일반 분양가 차이 3 분 만에 이해하세요"  
3. "A 단지 예시: 재개발 조합원이 왜 일반보다 5 억 더 싸게 살 수 있을까?"

### 태그 (최대 15 개)
```
#재개발 #조합원분양 #일반분양 #중개사교육 #부동산트렌드 #아파트투자 #재개발절차 #공인중개사
```

### 해시태그 (#)
```
#재개발조합원 #조합원분양가 #일반분양가 #부동산정보 #중개사추천 #아파트가격비교
```

### 커뮤니티 탭 활용
- 업로드 1 시간 전: "내 채널에 재개발 조합원 분양가 차이 3 분 만에 설명하는 영상 올릴게요. 미리 알림 받으시면 좋아요!" — 핀으로 고정  
- 업로드 직후: "이 영상 보는 중이라면 구독 필수! 다음 영상에서 '중도금 무이자 대출' 팁을 알려드릴게요."

## 💰 예상 효과 (KPI)
| 지표 | 목표치 | 측정 방법 |
|------|--------|-----------|
| 조회수 (24 시간 내) | 1,000~3,000 명 | 유튜브 스튜디오 → "조회수" 탭 |
| 평균 시청 지속율 | 50% 이상 | 유튜브 스튜디오 → "시청 지속율" 그래프 |
| 구독 전환율 | 2.5% 이상 | 업로드 24 시간 후 분석 |
| 클릭률 (CTR) | 8% 이상 | 썸네il + 제목 최적화 여부 확인 |

## ⚠️ 주의사항
- **법적 준수**:  
  - 실제 사례 사용 시 "예시"라고 명시  
  - 가격 비교는 "실제 시장 데이터 기반"이라고 언급  
- **알고리즘 대응**:  
  - 첫 1 시간: 제목/썸네일 수정 불가 (최악의 경우, YouTube 에러 발생)  
  - 업로드 직후 30 분: 커뮤니티 탭 고정 댓글로 "구독 필수" 유도

# 🖼️ YouTube 썸네일 디자인 브리프 (시리즈 1 화)

## 📌 목표 및 기준
- **목표**: 시리즈 1 화 영상 클릭률 (CTR) 8% 이상 달성  
- **대상**: 시니어 공인중개사 (60 대 이상) → 가독성, 대비, 직관적 이해 필요  
- **규격**: YouTube 권장 1280×720 px (16:9), 최소 2MB 파일 크기  

## 🎨 디자인 원칙
| 원칙 | 적용 방법 | 예시 |
|------|-----------|-------|
| **고대비** | 노란 배경 + 검은/빨간 텍스트 | `노란 #FFD700` + `검은 #000000` |
| **직관적 이해** | 도면 + 가격 그래프 + 화살표 | 왼쪽: 재개발 아파트 도면, 오른쪽: 가격 비교 (↑↓) |
| **시니어 눈 맞춤** | 24pt 이상 텍스트, 한글 폰트 '나눔고딕' | `18pt` → `24pt` → `30pt` |
| **가독성 확보** | 흰 배경 + 검은 그림자 | `흰색 #FFFFFF` + `검은 그림자 #000000` |

## 🎯 썸네일 옵션 3 개 (Designer 작업)

### 옵션 A: 도면 + 가격 그래프
```
[왼쪽] 재개발 아파트 도면 (실제 사진 또는 CAD 도면)  
[오른쪽] 가격 비교 그래프 (빨간 화살표↑ "조합원 더 싸다!")  
[하단] 대형 텍스트 "재개발 조합원 vs 일반 분양가"  
```

### 옵션 B: 대형 텍스트 + 아파트 전경
```
[중앙] 대형 텍스트 "재개발 조합원 vs 일반 분양가"  
[배경] 아파트 전경 (창밖 풍경)  
[하단] 작은 텍스트 "3 분 만에 이해하기"  
```

### 옵션 C: 인터뷰 사진 + 가격 표
```
[왼쪽] 재개발 중개인 인터뷰 사진 (자연스러운 표정)  
[오른쪽] 가격 표 (수식 계산기 느낌, 예를 들어 `1 억 5 천만 vs 2 억`)  
[하단] 대형 텍스트 "조합원 왜 더 싸? 이유 알려줘!"  
```
