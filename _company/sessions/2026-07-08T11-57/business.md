# MVP 필수 기능 명세: 가격 효율성 지수 기반 SaaS

## 1. 정의 (MVP 기준)
**'가격 효율성 지수'** = `(매물 정보 입력 시간 - 블로그 생성 완료 시간) / (입력된 매물 정보의 AI 최적화 정확도)`  
- **높은 점수**: 사용자가 빠르고 정확하게 매물을 등록하고, SaaS 가 자동으로 고품질 콘텐츠로 변환함.  
- **MVP 적용**: MVP 에는 이 지수를 계산할 수 있는 **기본 로직** (예: 입력 폼 필드 완료 비율, AI 생성 텍스트 길이/명확성 점수) 만 포함하고, 정교한 모델은 2 단계에서 구현.

## 2. 필수 기능 목록 및 우선순위
### 🥇 Priority 1 (MVP 핵심 - 즉시 개발)
| 기능 | 설명 | 가격 효율성 지수 연관성 |
|------|------|--------------------------|
| **매물 정보 입력 UI** | 시니어 중개사도 쉽게 입력할 수 있는 폼 (필드: 주소, 재원, 용도, 사진 등) | 입력 시간 단축 → 점수 상승 |
| **매물 데이터 구조화 AI** | 텍스트 설명을 `PropertyListing` JSON 으로 자동 변환 (필수 필드 누락 시 경고) | 정확도 측정 기반 지수 계산 |
| **블로그 자동 생성 엔진** | 매물 정보 + 네이버 블로그 API 연동 → 포스팅 JSON 생성 | 생성 품질 (글자 수, 구조화 점수) 반영 |
| **카드 렌더링 및 저장** | 기본 템플릿 (`basic`) 과 추가 템플릿 (`flyer`, `a4doc`) 의 PNG/HTML 출력 | 렌더링 시간 + 해상도 최적화 |
| **가격 효율성 지수 계산기 (기본)** | 위 데이터 기반으로 점수를 실시간 산출하고 UI 에 표시 (예: "이 매물 등록 효율: 85점") | MVP 핵심 지표 제공 |

### 🥈 Priority 2 (다음 스텝 - 프로덕션 준비)
- **경쟁 매물 분석**: 동일한 지역/종류 매물의 평균 등록 시간 및 블로그 생성 품질 비교.  
- **자동 최적화 제안**: 지수가 낮은 필드 (예: 설명 누락) 를 AI 가 자동으로 채워주는 기능.  
- **프리미엄 알림**: 고효율 사용자가 Pro 버전으로 유도하는 인센티브 메세지.

### 🥉 Priority 3 (후기 단계 - 확장성 확보)
- **AI 기반 트렌드 예측**: 등록 효율이 높은 매물 특징을 분석하여 새로운 상품 구조화.  
- **다국어 지원**: 영어/일본어 등 글로벌 중개사 타겟팅 시 가격 효율성 지수 국제 비교.
