# 📺 레오 — 사용자로부터 YouTube API 키 및 채널 ID를 요청하고, 정보 수신을 대기 상태로 설정하라. 데이터 확보 즉시 영상 스크립트 작성 단계로 전환할 준비를 하라.



📺 레오: 작업 시작합니다.

🔴 **YouTube API 키와 내 채널 ID 가 아직 입력되지 않았습니다.**  
이 두 가지 정보가 없으면 분석 도구들이 작동하지 않습니다 (트렌드 스나이퍼·내 영상 체크·댓글 수집기 모두 마찬가지).

**[요청 사항]**
1. **YouTube Data API v3 키** 발급: https://console.cloud.google.com/ → YouTube Data API v3 활성화 후 인증 토큰 복사  
2. **내 채널 ID**: 유튜브 스튜디오 → 설정 → 일반 정보에서 `Channel ID` 확인 (또는 URL 에서 `channel=UC...` 부분의 코드)

두 정보를 입력하면 바로 `youtube_account.json` 파일에 저장하고, 데이터 기반 분석을 재시작하겠습니다.
