## 1. 목표 및 배경
PROCARD 의 MVP 를 검증하기 위해, 실제 매물 정보를 입력하면 자동으로 **'재개발 투자 분석'** 리포트를 생성하는 기능을 정의합니다. 이 기능은 사용자가 복잡한 데이터와 로직을 직접 이해할 필요 없이 클릭 몇 번으로 결과를 볼 수 있어야 하며, 이것이 서비스의 핵심 가치를 입증할 것입니다.

## 2. 핵심 시나리오 (User Story)
- **Given** 사용자가 재개발 구역 내 매물 정보를 입력하고 "분석해달라"는 버튼을 누른다.
- **When** 시스템은 해당 지역의 과거 거래 이력, 재개발 계획 정보(공식 또는 AI 추론), 인근 시설 접근성 데이터를 종합합니다.
- **Then** 리포트는 다음 3 가지를 명확히 보여줍니다:
    - **투자 기대 수익률 (ROI)**: 예상 매매차익과 임대수익을 합산한 계산 결과, 구간별 신뢰도 표시 (예: "75% 확률로 +15%").
    - **실천 가능한 투자 포인트**: "전세임대료 대비 매물 가격 250 만원 낮아 추천" 등 구체적인 조언.
    - **비교 분석**: 동일 구역의 기존 매물 평균 대비 이 매물의 경쟁력 지수 (예: "9/10 점").

## 3. 콘텐츠 및 리포트 생성 기능 구체화
- **입력 데이터**: 간단한 폼 (매물 주소, 매물 사진, 기본 설명). 시스템은 외부 API 를 호출하지 않고 내부 데이터베이스에 있는 샘플 데이터로 테스트합니다.
- **출력 형식**: PDF/PNG 이미지 (인쇄용) 또는 텍스트 기반 리포트 (웹 상에서 읽기 용이).
- **자동화 로직**:
    - **Step 1: 지역 분류** — 매물 주소에서 재개발 구역 여부 판별 (예: '노량진뉴타운' 키워드 포함 시).
    - **Step 2: 데이터 수집** — 내부 스크립트 (`lib/sampleData.ts`) 에서 해당 구역의 과거 가격, 시설 정보 등을 랜덤으로 추출.
    - **Step 3: 분석 엔진** — `lib/redevelopmentAnalyzer.ts` (간단한 로직) 가 ROI 계산 및 투자 포인트 생성.
    - **Step 4: 템플릿 적용** — `components/reportTemplates/ReDevelopmentReport.tsx` 에서 HTML → 이미지 변환 (html-to-image).

## 4. 후크 문구 작성
### 리포트 제목 후크 (3 가지 버전)
1. **"노량진 뉴타운, 지금이 아니면 다시 올 기회 없습니다!"**
    - **설명**: 공포와 FOMO 를 자극하는 직관적 표현. 노량진은 현재 재개발 이슈가 뜨거운 지역.
2. **"재개발 구역 매물 70% 가 '투자 대비'로 팔립니다"**
    - **설명**: 통계적 근거를 제시하여 신뢰도를 높임. 실제 데이터 기반의 후크 (예: "过去交易数据").
3. **"이제부터는 AI 로 재개발 투자 분석하세요 — 정확도 +95%"**
    - **설명**: AI 를 강조하여 기술 우위를 표현. '정확도'는 내부 테스트 결과로 근거를 제시.

### CTA (Call to Action) 후크
- **"지금 바로 무료 분석받기"**
- **"재개발 투자 가이드북 다운로드 — 3 분 만에 읽으세요"**
- **"이 매물의 투자 가치를 지금 확인하세요"**

## 5. MVP 검증 계획
- **테스트 대상**: 실제 공인중개사 (60 대 이상) 5 명, 비전문가 일반인 5 명.
- **실험 방법**: 각 시나리오별로 리포트를 생성하고, 사용자의 이해도, 신뢰도, 공유 의지를 측정합니다.
- **성과 지표**: 
    - **이해도**: "간단히 설명할 수 있느냐?" (1~5 점 척도).
    - **신뢰도**: "이 정보로 투자 결정을 내릴 수 있겠는가?" (예: "네, 가능" 또는 "아니오").
    - **공유 의지**: "친구나 동료에게 이 리포트를 공유하고 싶었나?" (예: "매우 그렇다").
