# 📊 MVP KPI 및 하이브리드 가격 모델 기반 최종 비즈니스 목표 확정

**작성일:** 2026. 7. 21  
**작성자:** 현빈 (Head of Business)  
**상태:** ✅ 확정  

---

## 1️⃣ 핵심 목표 (Core Objective)
공인중개사를 위한 부동산 매물카드/전단지 생성 서비스 `PROCARD` 의 MVP 가 **실제 결제 전환을 유도하는 검증 가능한 프로토타입**이 되는 것.  
- **수익성 목표:** CAC < $70, LTV > $180 달성  
- **성장 목표:** 월 구독자 $29/명 기반 MRR (Monthly Recurring Revenue) 성장  

---

## 2️⃣ 하이브리드 가격 모델 (Hybrid Pricing Model)
**사용자 경험 + 수익성 균형을 위한 전략적 설계**

| 구성 요소 | 금액 | 역할 |
| :--- | :--- | :--- |
| **월 구독료** | **$29/월** | 지속적인 수익 흐름 확보, 기본 기능 무제한 제공 |
| **매물당 비용** | **$0.5 ~ $1** (가변) | 고품질 카드 디자인 시 추가 비용 부과 (원본 이미지 사용 등) |

**💡 전략적 의도:**  
- **월 구독료 ($29):** 초기 진입 장벽 낮춤, 기본 기능 (매물 생성, 블로그 자동작성) 무료 또는 제한 제공 후 유료 전환 유도
- **매물당 비용:** 고품질 카드 제작 시 추가 수익 창출, 사용자 니즈에 따른 맞춤형 옵션 제공

---

## 3️⃣ 웹 페이지 프로토타입 핵심 성과 지표 (KPI)

### 🎯 전환율 및 유입
| KPI | 목표치 | 측정 방법 |
| :--- | :--- | :--- |
| **랜딩 페이지 전환율** | ≥ 3.5% | `google_analytics4` 이벤트 분석 |
| **무료 체험판 가입 전환율** | ≥ 15% | `free_trial_signup_event` |
| **가격 모델 업그레이드 전환율** | ≥ 8% (월 $29 → 구독자) | `upgrade_to_pro_event` |

### 💰 수익성 및 성장
| KPI | 목표치 | 측정 방법 |
| :--- | :--- | :--- |
| **CAC (Customer Acquisition Cost)** | ≤ $70 | 마케팅 비용 / 신규 유료 사용자 수 |
| **LTV (Lifetime Value)** | ≥ $180 | 월 구독료 × 평균 사용 기간 (예: 6 개월) = $29 × 6 = $174 → 추가 수익 확보 필요 |
| **MRR (Monthly Recurring Revenue)** | ≥ $5,000 (초기 목표) | `mrr_report` 이벤트 분석 |

### ⚙️ 운영 및 안정성
| KPI | 목표치 | 측정 방법 |
| :--- | :--- | :--- |
| **이탈률 (Churn Rate)** | ≤ 5% / 분기 | `user_churn_event` 분석 |
| **API 응답 시간** | < 200ms (Gemini 호출 포함) | `api_response_time_ms` 이벤트 분석 |
