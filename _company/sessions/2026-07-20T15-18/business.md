# 🎯 수익화 우선순위 재평가 및 실행 계획 초안

## 📌 현황 및 문제 정의

- **현재 진행 중 작업**: 데이터 매핑 자동화 로직 안정화 (코다리), YouTube API 키 확보 (레오/영숙), 콘텐츠 전략 수립 (Writer, Designer).
- **핵심 목표**: 공인중개사 결제 100건 달성을 위한 수익화 모델 검증.
- **문제점**: 현재 진행 중인 작업들이 '결제'로 직접 연결되지 않아, 추가적인 가치 제안이 필요함.

## 🔄 우선순위 재평가 (CEO 지시 반영)

### 기존 수익화 가설 및 한계
1. **기존 PROCARD 서비스 (무료 → PRO)**: 블로그 자동 생성 기능 유료 전환.  
   - **한계**: 사용자가 직접 AI 키 입력 및 블로그 계정 연동 필요, UX 복잡도 높음.  
2. **인포그래픽 템플릿 판매**: Scene-by-Scene 비주얼 전략 기반 판매.  
   - **한계**: 60대 이상 시니어가 별도 파일 구매·적용 어려움.  
3. **재개발 투자 분석 기능 (신규 제안)**: PROCARD 앱 내 '재개발 분석' 탭 추가, AI 로직으로 조합원/분양가 비교, 이주비 대출 정보 제공.  
   - **강점**: 기존 매물 데이터와 연계 가능, 중개사 니치한 정보 제공, 유료 구독 모델과 자연스럽게 연결.

### 🎯 최우선 작업 선정: **'재개발 투자 분석' 기능 추가 및 유료화 검증**
- **이유**: 레오/영숙의 YouTube 콘텐츠 전략과 맞물려 '재개발 아파트 투자'라는 키워드로 트래픽 유입 가능, PROCARD 앱 내 기능 확장으로 기존 사용자에게도 가치 제공.
- **수익화 모델**: Freemium → Pro (월 구독 9,900원) 또는 기능별 인가료 (1 매물당 5,000원).

## 📋 실행 계획 초안

### 단계 1: MVP 검증 (2~3 주)
- **코다리**: '재개발 투자 분석' AI 로직 구현 준비.  
  - 필수 데이터: 조합원 수, 분양가 기준, 이주비 대출 금리 등.  
  - 기존 PROCARD 매물 스키마 (`PropertyListing`) 와 연동 가능하도록 설계.  
- **현빈**: 사용자 피드백 수집 계획 및 A/B 테스트 디자인.  
  - 무료 사용자에게 '재개발 분석' 기능 시연 버전 제공, 유료 전환 유도 문구 삽입.  
- **레오/영숙**: YouTube 콘텐츠에 '재개발 투자 분석' 기능 홍보 포함.  
  - '재개발 아파트, 어떻게 분석해야 하나요?' 시리즈 제작.

### 단계 2: 가격 전략 (1 주)
- **경쟁사 분석**:  
  - **부동산 AI 서비스 A**: 매물 분석 유료 (월 15,000원).  
  - **부동산 정보 B**: 재개발 예측 보고서 (1 건당 3,000원).  
  - **수익화 가설**: PROCARD 의 '재개발 분석' 기능은 월 9,900 원 (저가 진입) 또는 매물당 5,000 원으로 설정.
- **가격 책정 전략**:  
  - 초기 할인 (70%): 월 2,970 원 → 사용 후 정가 전환.  
  - 번들 옵션: '인포그래픽 템플릿' + '재개발 분석' 번들 (월 14,900 원).

### 단계 3: A/B 테스트 및 피드백 수집
- **테스트 방법**: 무료 사용자에게 '재개발 분석' 기능 시연 버전 제공 → 유료 전환 유도 문구 삽입.  
- **피드백 채널**: 앱 내 팝업, YouTube 댓글 모니터링.  
- **목표**: 유료 전환율 5% 이상 달성 (기존 PROCARD 의 유료 전환율 참고).
