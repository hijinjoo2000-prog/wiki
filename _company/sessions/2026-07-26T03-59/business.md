# 🎨 MVP 디자인 요구사항 (지식 저널 + 유료 컨설팅)

## 1. 디자인 방향성
- **톤앤매너**: '전문성 + 신뢰감' (공인중개사 대상 유료 서비스)
- **목표**: 첫 유료 고객 확보 및 전환율 최적화
- **스타일**: 깔끔하고 직관적인 UX, 모바일 우선 디자인

---

## 2. 페이지 구조 및 기능 요구사항

### 1. 랜딩 페이지 (Landing Page)
- **헤더**
    - 로고 + 네비게이션 메뉴 (홈, 지식 저널, 유료 컨설팅, 가격)
    - CTA 버튼: "지금 무료 샘플 보기"
- **메인 섹션**
    - 슬로건: "지식 저널로 부동산 정보를 바로 확인하세요"
    - 무료 콘텐츠 미리보기 (게시글 3 개) + 유료 구독 유도 문구
    - 가격 비교 테이블 (Starter/Pro 번들 옵션)
- **가격 섹션**
    - Starter: 월 $5 / 지식 저널 접근권
    - Pro: 월 $15 / 지식 저널 + 1:1 컨설팅 30 분
    - 번들 할인 안내

### 2. 지식 저널 페이지 (Journal)
- **게시글 목록**
    - 카테고리별 필터 (부동산, 법률, 투자 등)
    - 무료/유료 태그 표시
- **게시글 상세**
    - 콘텐츠 미리보기 + 결제 버튼 (Stripe 연동)
    - 댓글 및 공유 기능

### 3. 유료 컨설팅 폼 (Consultation Form)
- **폼 항목**: 이름, 연락처, 문의 내용, 결제 정보
- **결제 페이지**: Stripe Connect 연동
- **성공/실패 처리 메시지**
- **문의 결과 안내** (24 시간 내 응답)

### 3. 구독 관리 페이지 (Subscription Management)
- 현재 구독 상태 확인
- 결제 주기 변경
- 취소 옵션 제공

---

## 3. 디자인 가이드라인
- **색상 팔레트**: 신뢰감을 주는 차분한 파란색 계열, 브랜드 컬러 사용
- **폰트**: 가독성 높은 sans-serif (예: Poppins, Roboto)
- **레이아웃**: 반응형 그리드 시스템 (Bootstrap/Tailwind CSS)
- **이미지**: 고품질 부동산 관련 이미지 사용

---

## 4. 다음 액션
- **디자이너**: MVP 페이지 프로토타입 디자인 제작 (Figma/Adobe XD)
- **코다리**: 디자인을 바탕으로 프론트엔드 구현 시작

📊 평가: 완료 — 디자이너에게 MVP 페이지 구조 및 기능 요구사항 전달.  
📝 다음 단계: 디자이너 Figma 프로토타입 제작 — 3 일 내 완료 목표.

# 💻 MVP 개발 요구사항 (지식 저널 + 유료 컨설팅)

## 1. 기술 스택 및 환경
- **프론트엔드**: React.js / Next.js
- **백엔드**: Node.js / Python (FastAPI)
- **데이터베이스**: PostgreSQL
- **결제 연동**: Stripe Connect API
- **호스팅**: Vercel / Heroku

---

## 2. 기능 요구사항

### M1: 결제 시스템 구현
- **Stripe Connect 연동**
    - 구독자 관리 및 번들 옵션 결제 처리
    - 환불/취소 로직 구현
- **결제 페이지**
    - 가격 전략에 따른 UI 렌더링
    - 결제 성공/실패 처리 알림

### M2: 콘텐츠 게시 및 문의 폼
- **게시글 CRUD API**
    - 카테고리별 필터링
    - 무료/유료 태그 설정
- **문의 폼 연동**
    - 유저데이터 수집 (이름, 연락처, 문의 내용)
    - 결제 정보 포함 (Stripe 연동)

### 구독 관리 페이지
- 현재 구독 상태 확인 및 변경
- 결제 주기 변경 (월간/연간 전환)
- 취소 옵션 제공
