## 🎯 CEO 지시: CTA 전략 극대화 행동 계획

### 1 단계: 데이터 수집 환경 조성
```bash
# ① youtube_account.json 에 API 키·채널 ID 입력 → 실제 채널 진단 실행
cd "/Users/seopro/에이전트 학교/_company/_agents/youtube/tools" && python3 youtube_account.py --help
```

### 2 단계: 분석 도구 연동 (API 키 입력 후)
- `channel_full_analysis` — 현재 채널의 **시청 지속율, 클릭률 (CTR), CPM** 등 수익화 지수 산출  
- `competitor_brief` — 경쟁 채널의 CTA 문구 패턴 분석 (예: "무료 체험 시작하기" vs "지금 바로 등록")  
- `trend_sniper` — 떡상 영상에서 **첫 30초 후크 + CTA 연결 패턴** 추출  

### 3 단계: 구체적인 행동 계획 (CTA 전략 브리프)
- **영상 1: "프로카드 AI로 매물 카드 3 분 만에 만들기"**  
  - 30 초 후크: "부동산 중개사님, 매물 등록부터 전단지 제작까지 2 시간씩 버셨죠? 이제 끝!"  
  - CTA 문구: "무료 체험 시작하기" → **Pro 번들 (49,000원) 으로 전환 유도**  
  - 수익화 지수 적용: 영상 마지막 15 초에서 **CTA 버튼 클릭 시 30 일 무료 기간 안내**  

### 4 단계: 실행 우선순위
- **가장 가치 있는 단일 작업:** `youtube_account.json` 파일 생성 → API 키·채널 ID 입력  
- 다음 에이전트: 레오 (데이터 수집 후 CTA 브리프 작성), 현빈 (수익화 지수 검증 및 번들 옵션 조정)
