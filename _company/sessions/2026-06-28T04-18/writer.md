# 📄 랜딩 페이지 콘텐츠 전략 초안: 번들 요금제 B (초기 고객 확보 특화)

**작성일**: 2026. 6. 28  
**타겟 청중**: 재개발/이주 지역 공인중개사, 특히 AI 기반 가격 효율성 분석을 활용하려는 중간~고급 실업자  
**핵심 가치 제안 (UVP)**: "AI 가 계산한 최적의 수수료 구조로 월 고정비용을 50% 절감하고, 실제 사례 기반 자동화 툴로 업무 시간 30% 단축"

---

## 🎯 랜딩 페이지 전체 구조 (Single Page)

### 1. 헤더 (Above the Fold)
- **배경**: 재개발 구역 지도 + AI 분석 그래프 오버레이  
- **Headline**: `재개발/이주 지역 공인중개사라면, 이 한 번의 투자로 월 고정비용을 반으로 줄이세요.`  
- **Subhead**: `AI 기반 가격 효율성 지수를 활용한 '번들 요금제 B' 는 단순 구독이 아닌, 실제 수익 모델을 만들어주는 파트너입니다. 14 일 무료 체험으로 즉시 검증하세요.`  
- **CTA 버튼 (Primary)**: `무료 체험 시작하기 →` (아래로 스크롤)  

### 2. 문제 제기 & 공감 유도
- **이미지**: 공인중개사가 계산기나 엑셀을 주워쓰며 고민하는 모습  
- **Headline**: `이런 고민, 다들 비슷하죠?`  
- **Body**:  
  - `재개발 구역은 가격 변동성이 심해서 매번 수동으로 분석해야 합니다.`  
  - `AI 툴을 써도 데이터가 제대로 연결되지 않아 오히려 시간이 더 걸립니다.`  
  - `고정 비용만 지출해도 실제 수익은 늘지 않습니다.`  

### 3. 해결책 소개: 번들 요금제 B
- **Headline**: `번들 요금제 B 로 한 번에 모든 문제를 해결하세요`  
- **Feature 리스트 (아이콘 + 간단한 설명)**:  
  - 📊 **AI 기반 가격 효율성 지수**: 지역별, 거래종별 최적 가격 모델 자동 생성  
  - ⚡ **실시간 데이터 연동**: 공공데이터 + 부동산 포털 API 를 한 번에 연결  
  - 💰 **초기 고객 테스트용 기본 패키지**: 별도 설정 없이 바로 활용 가능한 CTA 버튼과 마케팅 문구 라이브러리  

### 4. 구체적인 성과 (Social Proof)
- **이미지**: 그래프 + 실제 공인중개사 testimonial  
- **Headline**: `이미 검증된 결과, 지금 바로 경험하세요`  
- **Body**:  
  - `재개발 구역 A 의 경우, AI 분석으로 30% 더 빠른 고객 확보 달성`  
  - `이주 지역 B 의 경우, 자동화된 계약서 작성으로 업무 시간 2 시간 단축`  

### 5. FAQ & 보안
- **Headline**: `다들 궁금해 하는 것들`  
- **Q&A 리스트**:  
  - Q: 번들 요금제 B 는 정말 비용 효율적인가요? → A: 실제 사례를 기반으로 최적화된 가격입니다.  
  - Q: 데이터 보안은 어떻게 하나요? → A: 암호화 및 GDPR 준수를 포함한 최신 보안 프로토콜을 사용합니다.  

### 6. 푸터 (Bottom CTA)
- **Headline**: `지금 바로 번들 요금제 B 로 시작하세요`  
- **CTA 버튼**: `무료 체험 시작하기 →`

## 🧠 마케팅 문구 라이브러리 추가 (후크 + CTA)

### A. Headline (메인 헤드라인)
```
재개발/이주 지역 공인중개사라면, 이 한 번의 투자로 월 고정비용을 반으로 줄이세요.
```
**변형안**:

- `14 일 무료 체험으로 번들 요금제 B 의 가치를 즉시 확인하세요.`  

### B. Subhead (부제목)
```
AI 기반 가격 효율성 지수를 활용한 '번들 요금제 B' 는 단순 구독이 아닌, 실제 수익 모델을 만들어주는 파트너입니다. 14 일 무료 체험으로 즉시 검증하세요.
```
**변형안**:  
- `재개발/이주 지역 공인중개사를 위한 최적의 가격 전략을 바로 적용해보세요.`  
- `AI 가 분석한 데이터로 월 고정비용을 50% 절감하고, 업무 시간 30% 단축하세요.`  

### C. CTA (Call to Action)
```
무료 체험 시작하기 →
```
**변형안**:  
- `지금 바로 번들 요금제 B 로 시작하세요`  
- `14 일 무료 체험을 신청해보세요`  
- `AI 기반 가격 효율성 지수를 지금 확인하세요`

## 🖼️ 시각 자료와의 연동 (Designer 에게 전달)

### 디자인 가이드라인

### Mockup 제작 시 고려 사항
- 랜딩 페이지 전체를 하나의 이미지로 제작하여 바로 활용 가능하게 함  
- 각 섹션별 배경, 텍스트 오버레이 등을 미리 준비  
- CTA 버튼은 항상 눈에 띄는 위치에 배치
