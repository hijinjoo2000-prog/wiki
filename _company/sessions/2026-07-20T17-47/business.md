42	## 3. 요구사항 명세서 (Requirements Specification)
43	
44	### 🎨 디자인 및 UX 요구사항
45	- **대문자 텍스트 + 친근한 한국어 안내**: 60 대 이상 사용자를 위한 큰 글씨 (`text-2xl`), 명확한 버튼 라벨 ('지금 시작하기'), 이모지 활용 필수  
46	- **ROI 시각화 전략 반영**: '1 일당 수익' 계산기, 경쟁사 대비 비용 절감 차트 등 ROI 를 직관적으로 보여주는 인포그래픽 포함 (Designer 의 작업 참조)  
47	- **채널별 템플릿 미리보기**: A4 문서, 인스타 카드, 블로그 포스트 미리보기를 한눈에 비교할 수 있는 '결과물 라이브러리' 섹션 배치  
48	- **법규 준수 배지**: '표시·광고법 자동 체크' 기능과 '공인중개사 인증' 로고를 상단 고정 배지로 배치  
49	
50	### 🛠️ 기술 요구사항
51	- **기술 스택**: React + TypeScript (Vite) + TailwindCSS (디자인 시스템)  
52	- **백엔드 연동**: `server.ts` API (`/api/generate-listing`, `/api/generate-blog`) 로직 직접 호출 시 2 초 이내 응답 보장  
53	- **결제 게이트웨이**: PayPal (현재 실패 데이터 있음 → Stripe 또는 Naver Pay 백업 옵션 추가)  
54	- **데이터 저장소**: Firebase 또는 Supabase (사용자 구독 상태, 생성된 카드 목록, 블로그 글 기록)  
55	
56	### 📝 콘텐츠 요구사항
57	- **가치 제안 (Value Proposition)**: '공인중개사 업무의 3 분 작업을 AI 가 대신해 드립니다' → 구체적 예시 (매물 설명 → 블로그 글 자동 작성 → 인스타 카드 PNG 저장)  
58	- **신뢰 유도 요소**: 실제 공인중개사 후기 (유료 전환 후), 성공 사례 (1 일 $50 수익 창출)  
59	- **가격 정책**: 3 단계 (무료 체험, PRO 월 구독 ($29), 매물당 비용 모델) 의 명확한 설명 및 번들 옵션 제시
