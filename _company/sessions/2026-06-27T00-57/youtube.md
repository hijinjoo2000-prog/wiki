CEO의 지시에 따라 최근 병목 현상 분석을 위한 데이터 수집이 필요합니다. 현재 YouTube API 키와 채널 ID 가 설정되지 않아 실제 영상 기획·제작 데이터를 기반으로 한 정량적 병목 원인 도출이 불가능합니다.

> 📊 채널 분석을 하려면 YouTube API 키와 채널 ID 가 필요해요. 헤더 우측 "👥 직원 에이전트 보기" 버튼 → YouTube 카드 ⚙️ 클릭 → API 키와 채널 ID 입력 후 다시 요청해주세요.

**병목 현상 추론 (데이터 기반 불가):**
- **자격증명 부족으로 차단됨** (Writer/Designer 산출물 단계)
  - `youtube_account.json` 설정 파일이 비어있거나 유효하지 않음 → 모든 YouTube 데이터 수집 도구 실행 불가
  - 결과: 영상 성과 분석, 시청자 패턴 파악, 경쟁 채널 벤치마킹 등 핵심 병목 원인 식별 불가
- **파일 시스템 접근 오류** (Designer/코다리 단계)
  - `designer.md` 파일 경로/권한 문제 → 산출물 전달 및 협업 프로세스 지연
  - 결과: 기획서 수정·업데이트 순환, 작업 시간 낭비

**해결 방안:**
1. `youtube_account.json` 에 API 키와 채널 ID 를 채워 넣는 것 (가장 우선)
2. 파일 시스템 권한을 확인하여 `designer.md` 등 산출물 접근 보장
3. 다음 주 실행 계획:
   - **API 설정 완료 후** `trend_sniper.py` 로 최근 떡상 영상 패턴 수집 → 병목 구간 식별
   - `comment_harvester.py` 를 통해 시청자 반응 키워드 누적 → 후크 단어가 명확해짐
   - 병목 해결 후, `auto_planner.py` 무인 반복 실행으로 데이터 기반 다음 액션 도출
