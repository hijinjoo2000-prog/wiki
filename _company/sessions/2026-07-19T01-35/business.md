# 🎨 Designer — 인포그래픽 디자인 강화 지침 (현빈 승인)

## [목표]
시니어 타겟에게 **추가 수익 창출** 가치를 직관적으로 전달하고, 결정을 유도하는 CTA를 최적화합니다.

---

## [핵심 지표 시각화 전략]

### 1️⃣ ROI 비교 (Basic vs Pro) — "1.85x" 강조
```
[현재 상태]
- Basic: 하루 60분 투자 → 1.34배 수익
- Pro:    하루 60분 투자 → 1.85배 수익

[시각화 개선안]
- 📊 바차트: 동일한 높이에 1.85배 높이로 Pro 표시 (직관적)
- 💰 숫자 강조: "Pro = Basic + 51% 더 많은 수익" 텍스트 오버레이
- 🔵 색상 대비: Basic(회색), Pro(금색 #FFD700) — 금색은 부/수익 상징

[필수 텍스트]
> "동일한 노력, 51% 더 큰 성과"  
> "Basic보다 Pro 선택 시 월 30만 원 추가 수익 가능" (구체적 환산)
```

### 2️⃣ 시간 절약 = 금전 → "하루 60분 = 10만 원"
```
[현재 상태]
- 시니어는 '시간' 개념보다 '돈'에 더 민감

[시각화 개선안]
- ⏱️ 시계 아이콘 + 💰 화폐 아이콘 겹침: "시간을 돈으로 변환" 직관적 연결
- 🔢 숫자 강조: "60분 = 100,000원" (작업 완료 후 자동 획득 가능)
- 📈 그래프: 일과 주별 시간 투자 누적 → 월 수익 산출 시각화

[필수 텍스트]
> "매일 60분이면 월 30만 원 수익 확보"  
> "시간을 돈으로 바꾸는 가장 쉬운 방법"
```

---

## [CTA 메시지 강화 — 금전적 가치 중심]

### 현재 상태:
- "지금 Pro 선택하세요" (일반적)

### 개선안 (3단계):

#### 단계 1: 손실 회피 + 금전적 기회 강조
```
❌ "지금 바로 시작해보세요"
✅ "이 기회를 놓치면 월 30만 원 수익을 잃게 됩니다"
   → 손실 회피 심리 활용
```

#### 단계 2: 구체적 액션 유도 (금전 환원 연결)
```
❌ "Pro로 업그레이드하세요"
✅ "지금 Pro 선택 → 1분 내 수익 전환 시작"
   → 즉각적 행동 + 금전적 결과 시각화
```

#### 단계 3: FOMO + 사회적 증거 추가
```
❌ "인기 있는 서비스입니다"
✅ "지난달 87% 공인중개사가 Pro 선택 — 월 150명 평균 수익"
   → 타겟 청중의 행동 패턴 반영
```

### 최종 CTA 조합 (시각화 적용):
```
🎯 메인 헤드라인:
   "하루 60분 투자 = 월 30만 원 추가 수익"
   
🔵 부제:
   "Basic 선택 시 놓치는 기회 — 1.85x ROI 확인해보세요"

🟠 CTA 버튼:
   [지금 Pro 선택 → 1 분 내 수익 전환]  
   → 금색 배경 + 흰 텍스트 + 화살표 아이콘
```

---

## [시각적 계층 구조]

### 가장 중요한 것 (시니어 눈높이):
1. **수익 숫자** — "30만 원", "1.85배" — 가장 큰 폰트 (#font-size: 2rem+)
2. **CTA 버튼** — 금색 배경, 흰 텍스트, 굵은 테두리
3. **시계 아이콘 + 화폐 아이콘** — 시간=돈 연결 시각화

### 부수적 정보 (필요하지만 덜 중요):
- 법적 문구 (표시·광고법 필수 표기) — 작게, 하단으로
- 회사 로고/연락처 — 중간 크기, 상단 우측

---
