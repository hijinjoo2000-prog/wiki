# 📊 Business Final KPI Spec — MVP 프로토타입 검증 기준

## 1. 핵심 성과 지표 (KPI) 정의

### 🎯 주요 전환율 목표
| 단계 | 최소 전환율 | 목표 전환율 | 측정 방법 |
|------|-------------|--------------|-----------|
| 방문자 → 구독가입 (Free Trial) | 2% | 3.5% | `window.print()` 후 "결제" 버튼 클릭 |
| Free Trial → Pro 결제 (모바일/PC) | 40% | 60% | PayPal 인테그레이션 테스트 |
| Pro 구독 → 블로그 자동 포스팅 | 80% | 95% | `generate-blog` API 호출 성공률 |
| 공인중개사 → 재구매 (LTV 증대) | - | 12회/년 | 쿠폰 코드, 번들 옵션 사용률 |

### 💰 가격 전략 검증
- **CAC($70)**: 구글 어드스 + 페이스북 타겟 광고(65세 이상 중개사), 리드 마그넷(전단지 샘플) 배포
- **LTV($180)**: 월 29,000원 기본구독 + 매물당 3,000원 수수료 = 연평균 $144.6 → 번들 옵션(블로그 자동화, AI 분석 등) 추가 시 LTV>$180 달성
- **ARPPU($49.80)**: Pro 사용자 중 70%가 번들 옵션 사용 (블로그 자동화 50%, AI 분석 20%)

### 🧪 MVP 검증 프레임워크
```yaml
验收 기준: 
  - 전환율: 3.5% 달성 시 프로덕트 마켓 피트 확인
  - LTV:CAC 비율 > 2.5 (180/70 = 2.57)
  - 페이지 로딩 속도 < 200ms (API 응답 시간 기준)
```

## 2. UX/UI 요구사항 (디자인 시스템 반영)

### 🎨 시각적 우선순위 (60대 이상 시니어 사용자 중심)
- **텍스트**: 18px+ 본문, 30px+ 헤드라인 (`font-size: text-2xl`)
- **이모지 활용**: "✅ 구독 시작하기", "🚀 블로그 자동화" 등 친근한 톤
- **색상**: 흰 배경 + 고대비 (검정/파랑), 포인트 컬러는 노랑/초록(행복감)

### 🖱️ 상호작용 패턴 (컴퓨터 미숙자 고려)
- **클릭 흐름**: 최대 3 단계로 단순화 (홈 → "구독 시작" → "결제")
- **버튼 크기**: 최소 48px 높이 (터치/마우스 정확도 확보)
- **피드백**: 버튼 클릭 시 "✅ 확인되었습니다!" 애니메이션

### 📱 모바일 우선 (중고거래 앱처럼 가벼운 느낌)
- **스크롤**: 자동 스크롤 방지, 한 화면에 핵심 정보만 표시
- **이미지**: 압축된 JPG/PNG (로딩 속도 최적화), 로케이션 기반 매물 추천

## 3. 기술적 요구사항 (시스템 안정성)

### ⚡ 성능 목표
- **API 응답 < 200ms**: Gemini 호출은 서버 사이드, 프론트엔드는 단순 `fetch()`
- **로딩 시간 < 1.5s**: CDN 호스팅(Vercel/Netlify), 이미지는 WebP 포맷

### 🛡️ 보안 및 컴플라이언스
- **보안 인증**: HTTPS 강제 (Let's Encrypt 자동 발급)
- **데이터 보호**: 사용자의 주소지·연령 정보는 암호화 저장
- **법적 준수**: 표시·광고법 필수 항목 자동 체크 (`lib/complianceRules.ts`)

## 4. 비즈니스 검증 체크리스트

### 📋 MVP 성공 기준 (30일 내 달성 목표)
- [ ] 전환율 2% 이상 달성 → 프로덕트 마켓 피트 확인
- [ ] LTV:CAC > 2.5 유지 → 가격 전략 타당성 입증
- [ ] 페이지 로딩 속도 < 200ms → 기술적 최적화 완료
- [ ] 공인중개사 결제 100건 목표의 3% 달성 → 3 건 확보


# 🎨 Designer Final Spec — MVP 프로토타입 UX/UI 요구사항

## 1. 디자인 시스템 (시니어 중개사 중심)

### 🎯 핵심 원칙
- **간단함**: 복잡한 기능은 숨기고, 핵심 기능만 강조 (구독 → 블로그 자동화)
- **친근함**: 이모지 활용, 따뜻한 색상 (노랑/초록 포인트), 친절한 안내 문구
- **신뢰감**: 공인중개사 로고·자격증 배지 표시, 보안 인증 마크

### 🖥️ 레이아웃 가이드라인
```yaml
구조: 
  - 헤더: "프로카드 2.0 | 구독하기" (30px, 굵은 글씨)
  - 메인: "무료로 매물 카드 만들기 ✨" (500x300 이미지 + CTA 버튼)
  - 섹션: "구독 플랜", "고객 리뷰", "FAQ" (2열 그리드)
  - 푸터: "프로카드 © 2026 | 개인정보처리방침"

색상 팔레트:
  - 기본: #FFFFFF 배경, #333333 텍스트
  - 포인트: #FFD700 (노랑), #90EE90 (초록)
  - 강조: #1E90FF (파랑 CTA 버튼)
```
