# 💼 현빈: 재개발 투자 분석 기반 수익화 전략 및 MVP 우선순위 분석

**작성일**: 2026. 7. 21  
**주요 관심사**: MVP 검증, 초기 가격 책정 (월 구독/매물당), 우선순위 결론

## 1. 🎯 핵심 가설: 재개발 투자 분석 기능의 수익화 모델

재개발 아파트 투자 분석은 단순한 정보 제공을 넘어 **투자 리스크를 줄이고 수익 기회를 명확히 보여주는 'AI 기반 가치 평가 도구'**로 포지셔닝합니다. 이를 통해 공인중개사에게 다음과 같은 가치를 제공합니다:
- **신뢰도 강화**: 객관적 데이터 (조합원/일반 분양가, 비례율, 이주비 대출 등) 로 전문성 입증.
- **고객 획득**: 재개발 관심층 (투자자) 의 신뢰를 얻어 중계 수수료 확보.

## 2. 💰 가격 책정 옵션 비교 및 우선순위 분석

| 옵션 | 월 구독 (SaaS) | 매물당 (프로젝트별) | 하이브리드 (권장 MVP) |
| :--- | :--- | :--- | :--- |
| **모델** | 기본 기능 무제한 + 프리미엄 리포트 | 1 개 매물 분석 시 $5~$10 | 월 $29 + 매물당 $3 |
| **타겟** | 데이터 활용도가 높은 중개사 | 단기 프로젝트 중심 소규모 사무소 | 진입 장벽 낮게, 지속성 확보 |
| **우선순위**| 1 위 (지속성 확보) | 2 위 (프로젝트별 ROI) | 3 위 (MVP 검증용) |

### 💡 결론: 하이브리드 모델이 MVP 검증에 가장 효과적
- **월 구독 ($29)** 은 AI 기반 분석 기능 (기본형) 을 제공하며, 지속적인 수익 흐름을 만듭니다.
- **매물당 ($3~$10)** 은 대형 프로젝트나 고난도 리포트 (예: 투자 시뮬레이션, 법륜리 분석) 를 위한 프리미엄 옵션입니다.
- **MVP 검증 목적**: 사용자가 월 구독으로 시작하되, 특정 기능 (예: "투자 리스크 감수성 분석") 을 사용할 때마다 매물당 요금을 추가로 지불하게 하는 구조를 테스트합니다.

## 3. 📊 MVP 검증용 사용자 반응 측정 항목

사용자 반응은 '결제 전환율'과 '기능 활용도'로 측정합니다. 다음 지표 (KPI) 를 설정하여 초기 피드백을 수집합니다:
- **CAC (고객 획득 비용)**: $50~$100 범위에서 목표 (무료 체험 7 일 → 유료 전환율 2% 이상).
- **LTV (생애 가치)**: 월 구독 $29 × 평균 사용 기간 6 개월 = $174 이상 목표.
- **기능 활용도**: '재개발 분석 리포트' 생성 빈도, '투자 시뮬레이션' 실행 횟수 등을 추적하여 고부가가치 기능 우선 개발 순서를 결정합니다.

## 4. 🚀 다음 단계: MVP 검증 실행 계획

1. **프로토타입 제작**: 위 가격 모델을 반영한 웹 페이지 (Landing Page) 와 간단한 리포트 생성 기능을 구현합니다.
2. **사용자 테스트**: 공인중개사 타겟의 소규모 그룹 (5~10 명) 에게 무료 체험을 제공하고, 반응 데이터를 수집합니다.
3. **가격 조정**: 사용자 피드백을 반영하여 가격과 기능 우선순위를 재조정합니다.
