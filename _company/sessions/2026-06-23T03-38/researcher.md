# 🚀 시장 데이터 & 가액 산정: AI 기반 매물 가치 예측 모델 (Phase 1)

## 1. 프로젝트 개요
- **목표**: 공인중개사 결제 100건 달성을 위한 '실시간 매물 가치 예측 시스템'의 초기 프레임워크 설계
- **범위**: 네이버 부동산 API, DIA+, 내부 CRM 데이터 연동 및 AI 모델 아키텍처 정의

## 2. 핵심 기술 스택 (추천)
| 구분 | 도구 | 용도 |
| :--- | :--- | :--- |
| **데이터 수집** | Selenium / Scrapy + 네이버 부동산 파싱 (비공식 API 대체안) | 실시간 매물, 거래 가격, 입지 데이터 |
| **저장소** | SQLite (초기) → PostgreSQL (확장 시) | 중개사별, 지역별, 업적별 데이터 분리 저장 |
| **AI 모델** | Python + Scikit-learn / XGBoost | 과거 거래 데이터 기반 가치 예측 |
| **실시간 연동** | WebSocket (네이버 C-Rank API) | 실시간 입지점수 변동 반영 |

## 3. 데이터 파이프라인 설계
### 3.1. 실시간 시장 데이터 확보 방법론
- **데이터원**: 네이버 부동산, DIA+, 국토교통부 공시가격 DB
- **파싱 주기**: 5 분마다 업데이트 (중개사별 우선순위별)
- **필드 정의**: 
  - `매물ID`, `지역명`, `거래가` (실제/공인), `입지점수(C-Rank)`, `건축연도`, `방수`, `주차대수`

### 3.2. AI 기반 가치 평가 모델 아키텍처
- **모델 유형**: XGBoost (해석성 확보) → LSTM (시간적 패턴 반영)
- **학습 데이터**: 
  - 최근 5 년간 실제 거래 가격, 입지점수, 건축연도 조합
  - 중개사별 판매 성공률 (결제 건수) 을 위한 '상담-매선' 연계 데이터
