## 🎯 목표
개발 환경이 안정화된 시점을 활용해 **핵심 가치 (간단한 클릭, 명확한 가격)**를 가장 빠르고 저렴하게 검증하는 MVP 를 출시합니다. 이를 통해 첫 결제 100건 목표 달성을 위한 피드백 수집과 시장 진입 장벽을 낮춥니다.

## 🧠 재검토된 수익화 모델 논리 (가격 전략)
시니어 중개사들은 복잡한 구독 개념보다 **"원하는 기능만큼만 내고, 불편함 없이 사용할 수 있어야 한다"**는 니즈가 큽니다. 이를 반영한 3 단계 번들 모델을 제안합니다.

| 패키지 | 가격 | 핵심 가치 | 타겟 청중 | 수익 기여도 |
| :--- | :--- | :--- | :--- | :--- |
| **Basic (무료)** | $0 | 매물 카드 생성 + 기본 블로그 템플릿 | 관심 있는 모든 중개사 | Lead Generation, 광고 노출 기반 |
| **PRO (월 19,800원)** | 1.9 만원 | 블로그 자동 게시 + 고급 디자인 템플릿 + 채팅 상담 기록 | **결제 100건 핵심 타겟** | 주요 수익원 (Recurring Revenue) |
| **Enterprise (구독+수수료)** | $50/월 + 거래 수수료 | 대용량 이미지 저장 + 전용 고객지원팀 + API 연동 | 대형 중개사무소 | 고단가 수익원 |

### 💰 가격 전략의 핵심: 심리적 장벽 낮추기
- **Basic**은 진입 장벽을 제로로 하여 사용자가 서비스를 "필요성" 없이도 인지하게 합니다. 이후 PRO 기능 (블로그 자동 게시) 을 강조하여 자연스러운 업그레이드 유도.
- **PRO 19,800 원**은 공인중개사들이 월 유지비용으로 쉽게 부담할 수 있는 금액입니다. 이는 기존 소프트웨어 (예: 카드 제작 앱 약 2~3 만원) 대비 매우 저렴하며, 블로그 자동 게시라는 강력한 가치를 제공합니다.
- **Enterprise**는 고단가 수익을 위해 설계되었지만, MVP 단계에서는 우선 PRO 를 검증하는 데 집중합니다.

## 🚀 MVP 로직 구현 우선순위 (1~3 개월)
개발 리소스 (코다리) 와 비즈니스 요구사항 (현빈) 을 종합하여 다음 순서로 개발해야 합니다.

| 순위 | 기능 | 기술적 우선순위 | 비즈니스 가치 | 예상 출시 시기 |
| :--- | :--- | :--- | :--- | :--- |
| **1** | **매물 카드 생성기 (Basic)** | `tsx server.ts` + `html-to-image` 로직 최적화 | 기본 기능 제공 및 Lead Generation | 2 주 내 |
| **2** | **블로그 자동 게시 (PRO 핵심)** | 네이버 블로그 API 연동 + Gemini 응답 구조화 | 주요 수익원이며, 시니어 중개사들이 가장 원하는 기능 | 1 달 내 |
| **3** | **간단한 대시보드 (KPI)** | React 컴포넌트 + localStorage 데이터 시각화 | PRO 구독의 가치를 입증하고 결제 유도 | 2 달 내 |

### 📋 MVP 개발을 위한 구체적 액션 아이템
- **Priority #1 (매물 카드 생성기)**: 현재 구현된 로직 (`components/cardtemplates/`, `lib/complianceRules.ts`) 을 유지하되, 성능 최적화 (이미지 압축) 와 오류 처리를 먼저 적용합니다.
- **Priority #2 (블로그 자동 게시)**: `generate-blog` 엔드포인트 (`server.ts`) 에서 네이버 블로그 API 연동 로직을 구현하고, `PropertyListing` 스키마와 템플릿 간의 일관성을 확보합니다.
- **Priority #3 (간단한 대시보드)**: PRO 구독자가 결제 후 보이는 "생성된 카드 수", "블로그 게시 내역" 등을 보여주는 매우 간단한 React 컴포넌트를 추가합니다.
