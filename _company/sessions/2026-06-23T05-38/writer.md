## 1. 이전 데이터 수집 및 레이블링 정리

- **MLS (Multi Listing Service)**: 미국/유럽 등 해외 시장 데이터 (비교 분석용)
- **대형 중개사 공인중개사 정보**: 전세임대료 산정 가이드라인

### 1.2 레이블링 규칙 (AI 가치 평가 모델 기반)
```python
# 가격 효율성 지표 (Price Efficiency Label)
labels = {
    "excellent": 0.95,   # 시장 평균 대비 5% 이상 절감
    "average": 0.70,     # 시장 평균 범위
    "high_risk": 0.40    # 시장 평균 대비 10% 이상 비쌈
}
```

### 1.3 데이터 파이프라인 (SSOT 구축)
- **원본 추출** → **정제** → **저장 (Parquet)** → **레벨링**  
  `cleaned_market_data.parquet` 스키마:
  ```json
  {
    "property_id": str,
    "location": str,
    "price_per_sqm": float,
    "efficiency_label": str,
    "last_updated": datetime
  }
  ```

## 3. 주요 섹션별 내용 및 예시 (후크/본문/CTA)

### 3.1 섹션: 기초 - 시장 데이터 이해하기
- **핵심 공식**: `가격 효율성 = (시장 평균 가격 / 실제 거래 가격)`
- **예시**:
  ```python
  # 네이버 API 로 얻은 아파트 가격 데이터
  market_avg_price = 15000000  # 평당 1,500 만 원
  actual_trade_price = 14200000 # 실제 거래 가격

  efficiency_label = (market_avg_price / actual_trade_price) - 1
  print(f"가격 효율성: {efficiency_label:.2%}")  # 결과: 5.63%
  ```

### 3.2 섹션: 심화 - AI 모델 적용
- **AI 모델**: 가격 효율성 지표 기반의 레이블링 파이프라인
  ```json
  {
    "excellent": {"efficiency": ">0.95", "color": "#4CAF50"},
    "average": {"efficiency": "0.70~0.95", "color": "#FFC107"},
    "high_risk": {"efficiency": "<0.70", "color": "#F44336"}
  }
  ```

### 3.3 섹션: 실무 - 보고서 작성법
- **고객별 맞춤형 가이드**: 고객 목적 (투자/자택) 에 따라 최적의 가격대 제시
- **법적 고려사항**: 전세임대료 간주 부과 기준, 중상급지 재개발구역 등
