# 📋 프로토타입 명세서: 공인중개사 결제 100 건 목표 달성용 Landing Page

**버전:** 1.0  
**작성일:** 2026-07-21  
**책임자:** 💼 현빈 (Business Head) & 🎨 Designer  

---

## 1. 비즈니스 목표 (Business Goals)

프로토타입이 달성해야 할 핵심 목표는 **'가짜 데이터 없이 실제 결제 전환을 유도하는 검증 가능한 MVP'**입니다.

| 목표 | 정의 | 성공 지표 (Success Metric) |
| :--: | :-- | :-- |
| **결제 100 건 달성** | 공인중개사들이 실제로 구독/수수료를 지불하도록 유도 | 30 일 내 유료 전환 5 명 이상 |
| **CAC < LTV** | 신규 고객 확보 비용이 평생 가치보다 낮게 유지 | CAC ≤ $70, LTV ≥ $180 (목표) |
| **초기 수익화** | MVP 검증 단계에서도 월 매출 $50 이상 발생 | 첫 유료 구독 3 개월 내 |

---

## 2. 핵심 KPI 대시보드 (Key Performance Indicators)

디자인과 개발 시 반드시 반영해야 할 측정 항목입니다. 실제 데이터가 들어오는 구조로 설계됩니다.

### 🎯 전환 중심 KPI
| 지표명 | 목표치 | 측정 포인트 |
| :--: | :--: | :--: |
| **사이트 방문 → 구독 시작** | 35% 이상 | 상단 '무료 체험' 버튼 클릭률, 가격 비교 섹션 스크롤 깊이 |
| **결제 페이지 완료율** | 60% 이상 | 결제 폼 진입 후 실제 결제 완료 비율 (Stripe/PayPal 연동 시) |
| **평균 주문 가치 (AOV)** | $29/월 (초기 구독) | 번들 옵션(기본 + 블로그 작성) 선택 비율, 업셀 성공률 |

### 💰 수익성 KPI
| 지표명 | 목표치 | 측정 포인트 |
| :--: | :--: | :--: |
| **LTV/CAC 비율** | ≥ 3.0 | 1 년 내 예상 구독료 / 신규 고객 확보 비용 (유입 채널별 분석) |
| **월간 재구독율** | 95% 이상 | 1 회 구매 후 자동 갱신/연장 가입 비율 (마찰 없는 UX) |
| **수수료 기반 매출** | $3~$10/매물 | 매물 생성 시 '블로그 작성' 옵션 선택 비율, PRO 계정 전환율 |

## 3. 요구사항 명세서 (Requirements Specification)

### 🎨 디자인 및 UX 요구사항
- **대문자 텍스트 + 친근한 한국어 안내**: 60 대 이상 사용자를 위한 큰 글씨 (`text-2xl`), 명확한 버튼 라벨 ('지금 시작하기'), 이모지 활용 필수  
- **ROI 시각화 전략 반영**: '1 일당 수익' 계산기, 경쟁사 대비 비용 절감 차트 등 ROI 를 직관적으로 보여주는 인포그래픽 포함 (Designer 의 작업 참조)  
- **채널별 템플릿 미리보기**: A4 문서, 인스타 카드, 블로그 포스트 미리보기를 한눈에 비교할 수 있는 '결과물 라이브러리' 섹션 배치  
- **법규 준수 배지**: '표시·광고법 자동 체크' 기능과 '공인중개사 인증' 로고를 상단 고정 배지로 배치  

### 🛠️ 기술 요구사항
- **기술 스택**: React + TypeScript (Vite) + TailwindCSS (디자인 시스템)  
- **백엔드 연동**: `server.ts` API (`/api/generate-listing`, `/api/generate-blog`) 로직 직접 호출 시 2 초 이내 응답 보장  
- **결제 게이트웨이**: PayPal (현재 실패 데이터 있음 → Stripe 또는 Naver Pay 백업 옵션 추가)  
- **데이터 저장소**: Firebase 또는 Supabase (사용자 구독 상태, 생성된 카드 목록, 블로그 글 기록)  

### 📝 콘텐츠 요구사항
- **가치 제안 (Value Proposition)**: '공인중개사 업무의 3 분 작업을 AI 가 대신해 드립니다' → 구체적 예시 (매물 설명 → 블로그 글 자동 작성 → 인스타 카드 PNG 저장)  
- **신뢰 유도 요소**: 실제 공인중개사 후기 (유료 전환 후), 성공 사례 (1 일 $50 수익 창출)  
- **가격 정책**: 3 단계 (무료 체험, PRO 월 구독 ($29), 매물당 비용 모델) 의 명확한 설명 및 번들 옵션 제시
