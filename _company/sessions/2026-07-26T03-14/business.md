# MVP 설계 문서: 지식 저널 + 유료 컨설팅

## 1. 핵심 목표 (KPI)
- **단기 (1 개월)**: 공인중개사 결제 100 건 달성, 월 매출 500 만 원 돌파
- **중기 (3 개월)**: 자동화 시스템 구축 완료, 고객 지원 인력 2 명 축소

## 2. MVP 기능 범위 (MVP Version 0.1)

### Phase 1: 트래픽 및 전환 유도
| 기능 | 설명 | 우선순위 |
| :--- | :--- | :--- |
| **지식 저널 라이브러리** | 공인중개사 실무 Q&A, 지역별 부동산 트렌드 리포트 (월간 무료 배포) | P0 |
| **유료 콘텐츠 샘플 보기** | 유료 컨설팅 패키지 중 1 개를 무료로 체험할 수 있는 '샘플' 기능 | P1 |

### Phase 2: 수익화 전환 포인트
| 기능 | 설명 | 우선순위 |
| :--- | :--- | :--- |
| **무료 상담 후 유료 솔루션 제안** | 첫 상담 (30 분) 시 무료, 이후 맞춤형 솔루션 제안 시 10% 할인 제공 | P0 |
| **'지식 저널 구독자 전용' VIP 커뮤니티** | 월 5 만 원, 프리미엄 정보 및 전문가 토크 참여 가능 (Stripe 연동 필요) | P0 |

### Phase 3: 결제 시스템 연동
| 기능 | 설명 | 우선순위 |
| :--- | :--- | :--- |
| **Stripe 결제 연동** | 코다리팀 진행 중. 웹페이지 디자인과 일관성 유지 필요 | P0 |
| **전자 서명 계약서 자동 생성** | 계약서 작성 → 전자 서명 → 자동 발송 (PDF) | P1 |

## 3. 디자인 가이드라인 (Designer 에게 전달)

### 시각적 요소 (Visual Identity)
- **색상 팔레트**: 기존 회사 브랜드 컬러 (`#0047AB`, `#FFC107`) 유지, 신뢰감을 위한 네이비 톤 강조
- **레이아웃**: 모바일 우선 설계. 정보 밀도 조절하여 3 초 안에 핵심 가치 전달 가능하도록 최적화

### UX 원칙
- **초기 진입 장벽 낮추기**: 무료 콘텐츠 → 유료 콘텐츠로 자연스럽게 전환하는 '스키마' 설계 (예: "이 리포트는 VIP 구독자만 볼 수 있습니다" 유도 문구)
- **신뢰감 강조**: 공인중개사 자격증 번호 인증, 성공 사례 데이터 시각화

## 4. 실행 일정 및 역할 분담

| 작업 항목 | 담당 에이전트 | 마일스톤 (2026/7/28 기준) |
| :--- | :--- | :--- |
| **웹페이지 디자인** | Designer | 기존 디자인 일관성 검토, MVP 기능 반영 |
| **Stripe 연동 구현** | 코다리 | 결제 화면 UI 와의 결합, 테스트 완료 |
| **콘텐츠 기획** | 현빈 (현행) | 지식 저널 라이브러리 초기 데이터 수집 (10 개 Q&A) |
| **법적 검토** | CEO / 외부 변호사 | 전자 서명 계약서 법적 유효성 검증 |

## 5. 가격 전략 제안 (Starter / Pro)

### Starter (신규 공인중개사 대상)
- **금액**: 월 3 만 원 (1 개월 무료 체험 포함)
- **내용**: 지식 저널 구독, 기본 상담 채널 오픈, VIP 커뮤니티 접근 불가

### Pro (성숙한 중개사무소 대상)
- **금액**: 월 8 만 원
- **내용**: Starter 포함 + 프리미엄 리포트 2 회/월 제공, 개인 멘토링 1 시간/월 제공, 전자 서명 계약서 자동 생성
