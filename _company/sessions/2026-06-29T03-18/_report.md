CEO 의 지시대로 YouTube API 키와 채널 ID 를 설정하여 데이터 기반 분석을 진행해야 합니다. 하지만 현재 시스템에는 API 키가 비어있고, 사용자로부터 직접 입력받아야 하는 상황입니다.

**🛑 실시간 데이터 — 시스템이 방금 도구로 가져온 진짜 출력**
```
❌ YOUTUBE_API_KEY 미설정. youtube_account.json 에 채워주세요.
─── YouTube 계정 / 채널 설정 ───
  API 키            : (빈 값)
  내 채널 핸들       : (없음)
  내 채널 ID        : (없음)
  감시 채널 (0 개) : (없음)
  경쟁 채널 (0 개): (없음)

⚠️  API 키가 비어있어요. 다른 도구들이 동작하지 않습니다.
   발급: https://console.cloud.google.com/ → YouTube Data API v3
```

**📊 평가: 대기 — YouTube API 키와 채널 ID 가 없으므로 데이터 기반 분석이 불가능합니다.**
