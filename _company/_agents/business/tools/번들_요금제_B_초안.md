# 💰 번들 요금제 B: 공인중개사 결제 100 건 달성을 위한 실행 로드맵 (초안)

## 📌 배경 및 목표
- **회사 목표:** 공인중개사의 결제 100 건 달성
- **핵심 전략:** 번들 요금제 B 를 통한 구독 기반 수익 모델 확립
- **타겟:** 기존에 단발성 비용만 지출하던 공인중개사 (도면, 광고비 등)

## 🎯 번들 요금제 B 기본 구성안 (가정 데이터 기반)
| 항목 | 내용 | 예상 가격 |
| :--- | :--- | :--- |
| **도면 제공** | AI 도면 생성/편집 도구 사용권 | 3,000 원/월 |
| **광고 연동** | 유튜브·블로그 채널 연동 및 자동 최적화 | 5,000 원/월 |
| **법률 가이드** | AI 기반 계약서 검토/용어 설명 (API) | 2,000 원/월 |
| **총 요금** | **10,000 원/월** (연 12 만원) | |

## 📊 가격 전략 및 수익 모델 (가설)
- **단가:** 월 10,000 원 → 1 년 계약 시 10% 할인 (9,000 원) 적용
- **수수료:** 결제 건당 500 원 수수료 (최대 2 만원/건)
- **추가 수익:** 연동된 채널의 광고 수익 분배 (예: 조회수 1,000 개당 5 원 → 번들 사용자에게 3 원 지급)
