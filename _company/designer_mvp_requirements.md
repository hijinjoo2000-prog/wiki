# 🎨 MVP 디자인 요구사항 (지식 저널 + 유료 컨설팅)

## 1. 디자인 방향성
- **톤앤매너**: '전문성 + 신뢰감' (공인중개사 대상 유료 서비스)
- **목표**: 첫 유료 고객 확보 및 전환율 최적화
- **스타일**: 깔끔하고 직관적인 UX, 모바일 우선 디자인

---

## 2. 페이지 구조 및 기능 요구사항

### 1. 랜딩 페이지 (Landing Page)
- **헤더**
    - 로고 + 네비게이션 메뉴 (홈, 지식 저널, 유료 컨설팅, 가격)
    - CTA 버튼: "지금 무료 샘플 보기"
- **메인 섹션**
    - 슬로건: "지식 저널로 부동산 정보를 바로 확인하세요"
    - 무료 콘텐츠 미리보기 (게시글 3 개) + 유료 구독 유도 문구
    - 가격 비교 테이블 (Starter/Pro 번들 옵션)
- **가격 섹션**
    - Starter: 월 $5 / 지식 저널 접근권
    - Pro: 월 $15 / 지식 저널 + 1:1 컨설팅 30 분
    - 번들 할인 안내

### 2. 지식 저널 페이지 (Journal)
- **게시글 목록**
    - 카테고리별 필터 (부동산, 법률, 투자 등)
    - 무료/유료 태그 표시
- **게시글 상세**
    - 콘텐츠 미리보기 + 결제 버튼 (Stripe 연동)
    - 댓글 및 공유 기능

### 3. 유료 컨설팅 폼 (Consultation Form)
- **폼 항목**: 이름, 연락처, 문의 내용, 결제 정보
- **결제 페이지**: Stripe Connect 연동
- **성공/실패 처리 메시지**
- **문의 결과 안내** (24 시간 내 응답)

### 3. 구독 관리 페이지 (Subscription Management)
- 현재 구독 상태 확인
- 결제 주기 변경
- 취소 옵션 제공

---

## 3. 디자인 가이드라인
- **색상 팔레트**: 신뢰감을 주는 차분한 파란색 계열, 브랜드 컬러 사용
- **폰트**: 가독성 높은 sans-serif (예: Poppins, Roboto)
- **레이아웃**: 반응형 그리드 시스템 (Bootstrap/Tailwind CSS)
- **이미지**: 고품질 부동산 관련 이미지 사용
